# Tampilan Zigma

Halaman ini menyajikan rangkuman visual dari seluruh layar antarmuka pengguna (UI) di Zigma. Setiap tampilan di bawah ini akan Anda temui saat mengikuti panduan bermain, mulai dari masuk ke aplikasi hingga melihat hasil akhir permainan.

---

## 1. Autentikasi & Menu Utama

### A. Layar Login
Layar pertama yang diakses user untuk masuk ke sistem Zigma menggunakan akun Google atau Guest.

![Layar Login Zigma](/images/login.png)

* **Fungsi**: Memverifikasi identitas pemain sebelum masuk ke menu utama.

---

### B. Home Page
Pusat navigasi setelah berhasil login untuk memilih mode permainan atau mengatur aplikasi.

![Home Page Zigma](/images/homepage.png)

* **Menu Utama**: Tombol **Join Game** dan **Host Game**.
* **Menu Ekstra (Burger Bar ☰ kanan atas)**: Bahasa (*Language*), Panduan (*How to Play*), Install PWA (*Install App*), Layar Penuh (*Fullscreen*), dan Keluar (*Logout*).

## 3. Antarmuka Sisi Host & Pemilihan Kuis

### A. Select Quiz (Katalog Kuis)
Katalog bagi Host untuk mencari dan memilih topik kuis yang akan digunakan.

![Halaman Select Quiz Zigma](/images/select-quiz.png)

* **Fungsi**: Memfilter paket kuis berdasarkan kategori, jenjang pendidikan, serta bahasa.

---

### B. Dialog Detail Kuis
Pop-up yang muncul ketika salah satu kartu kuis diklik.

![Dialog Detail Kuis](/images/dialog-detail.png)

* **Play Now**: Mengarahkan ke mode latihan mandiri (**Tryout**).
* **Start Quiz**: Membuat sesi multiplayer baru sebagai **Host**.

---

### C. Halaman Setting (Pengaturan Sesi)
Layar penyesuaian konfigurasi sebelum permainan dimulai.

| Setting Host | Setting Tryout |
| :---: | :---: |
| ![Setting Host](/images/setting%20host.png) | ![Setting Tryout](/images/setting%20tryout.png) |

* **Pengaturan Umum**: Mengatur tingkat kesulitan map permainan (*Difficulty*), durasi waktu, jumlah soal, dan audio (*sound*).
* **Perbedaan Utama**: Pada Setting Tryout tersedia fitur **pemilihan karakter**, sedangkan pada Setting Host tidak ada.

---

### D. Host Lobby
Ruang tunggu yang ditampilkan di layar Host sebelum memulai pertandingan multiplayer.

![Host Lobby Zigma](/images/host-lobby.png)

* **Fungsi**: Menampilkan **PIN Room**, **QR Code**, **Link join** daftar pemain yang telah bergabung, dan tombol **Start Game**.

---

### E. Host Monitor (Progress Permainan)
Layar pemantau live saat pertandingan sedang berjalan.

![Host Monitor Zigma](/images/host-monitor.png)

* **Fungsi**: Memantau pergerakan karakter seluruh pemain di peta 2D dan melihat progres pengerjaan soal secara *real-time*.

---

### F. Leaderboard (Klasemen Akhir)
Layar penutupan pertandingan yang ditampilkan di layar Host.

![Leaderboard Zigma](/images/leaderboard.jpeg)

* **Fungsi**: Menampilkan podium juara 3 besar dan klasemen skor akhir seluruh pemain.

---

## 4. Antarmuka Sisi Player

### A. Waiting Room (Ruang Tunggu Pemain)
Layar tunggu pemain setelah memasukkan kode room.

![Waiting Room Zigma](/images/waitingroom.png)

* **Fungsi**: Pemain dapat memilih dan mengkustomisasi tampilan karakter sambil menunggu Host menekan tombol mulai.

---

### B. Arena Gameplay 2D & Modal Kuis
Layar permainan interaktif tempat pemain beraksi dan menjawab soal.

| Arena Gameplay 2D | Modal Kuis Interaktif |
| :---: | :---: |
| ![Arena Gameplay](/images/gameplay.png) | ![Modal Kuis](/images/sistem-kuis.png) |

* **Arena Gameplay**: Karakter menjelajahi arena tilemap 2D dengan joystick/keyboard untuk menebas monster dan membuka peti harta.
* **Modal Kuis**: Layar pop-up pertanyaan pilihan ganda yang muncul saat pemain berinteraksi dengan monster kuis.

---

### C. Layar Result (Hasil Pemain)
Layar yang muncul di perangkat masing-masing pemain setelah sesi permainan berakhir.

![Result Pemain Zigma](/images/result.png)

* **Fungsi**: Menampilkan total skor yang dikumpulkan dan peringkat akhir pemain secara individu.
