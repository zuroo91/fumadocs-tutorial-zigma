# Join Game

![Tampilan Join Game](/images/join.png)

Jika Anda ingin bermain bersama teman dan teman Anda sudah membuat ruangan, Anda dapat bergabung melalui menu Join Game.

### Langkah-langkah Bergabung:
1. Dari halaman **Dashboard**, pilih opsi **Join Game**.
2. Masukkan **Kode Room** (PIN) yang diberikan oleh Host.
3. (Opsional) Scan kode QR jika Host menampilkannya di layar.
4. Klik tombol **Join** atau **Masuk**.
5. Anda akan diarahkan ke **Waiting Room** sambil menunggu Host memulai permainan.
