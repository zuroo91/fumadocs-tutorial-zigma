# Home Page

Setelah login, Anda akan berada di halaman **Home Page**. Di sini, Anda dapat memilih mode permainan dan mengakses berbagai pengaturan aplikasi.

![Tampilan Home Page Zigma](/images/homepage.png)

## Menu Utama

### Join Game
Bergabung ke ruangan (room) yang sudah dibuat oleh pemain lain. Anda akan diminta memasukkan **kode unik** yang diberikan oleh Host untuk bisa masuk ke room tersebut.

### Host Game
Mengarahkan Anda ke halaman **Select Quiz**, tempat Anda memilih kuis yang ingin digunakan. Setelah membuka detail sebuah kuis, tersedia dua pilihan:
- **Mulai / Host Game** — Membuat sesi multiplayer baru sebagai Host dan mengundang pemain lain.
- **Tryout** — Memainkan kuis tersebut secara mandiri tanpa perlu pemain lain.

---

## Menu Lainnya

Menu-menu berikut dapat diakses melalui **ikon burger bar (☰) di sebelah kanan atas** layar.

### Language
Mengganti bahasa antarmuka aplikasi sesuai preferensi Anda.

### How to Play
Menampilkan panduan singkat cara bermain Zigma, cocok untuk pemain baru yang ingin memahami alur permainan.

### Install App
Menginstal Zigma sebagai aplikasi (PWA) langsung ke perangkat Anda agar bisa dimainkan seperti aplikasi native tanpa membuka browser.

### Fullscreen
Mengaktifkan atau menonaktifkan mode layar penuh untuk pengalaman bermain yang lebih imersif.

### Logout
Keluar dari akun Anda dan kembali ke halaman login.
