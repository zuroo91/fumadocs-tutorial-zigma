# Tryout (Mode Latihan)

Mode **Tryout** memungkinkan Anda memainkan kuis secara **mandiri** tanpa membutuhkan pemain lain. Cocok untuk latihan atau mencoba soal sebelum sesi multiplayer.

## Cara Mengakses Tryout

Tryout diakses melalui halaman **Select Quiz**, bukan dari Dashboard:

1. Dari **Home Page**, klik **Host Game** → masuk ke halaman **Select Quiz**.
2. Pilih kuis yang ingin dicoba → muncul **pop-up / dialog detail kuis**.
3. Klik tombol **Play Now** → diarahkan ke halaman **Setting** untuk mengatur konfigurasi sesi.
4. Selesai mengatur, klik **Lanjut** untuk langsung masuk ke permainan secara mandiri.

## Catatan

- Skor di mode Tryout tidak masuk ke dalam klasemen kompetitif multiplayer.
- Mode ini cocok untuk membiasakan diri dengan kontrol dan alur permainan sebelum bermain bersama orang lain.
