# Waiting Room (Ruang Tunggu Pemain)

![Tampilan Waiting Room](/images/waitingroom.png)

Setelah berhasil masuk menggunakan kode room, Anda akan ditempatkan di **Waiting Room**.

### Yang Dapat Anda Lakukan:
- **Pilih Karakter**: Anda dapat mengkustomisasi tampilan karakter Anda (misalnya: mengganti model karakter atau rambut).
- **Bersiap**: Pastikan koneksi internet stabil sambil menunggu instruksi dari Host.
- Permainan akan otomatis dimulai dan Anda akan dipindahkan ke arena permainan (Gameplay) ketika Host mengklik tombol "Mulai".
