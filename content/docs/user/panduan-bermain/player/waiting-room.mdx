# Waiting Room (Ruang Tunggu Pemain)

![Tampilan Waiting Room](/images/waitingroom.png)

Setelah berhasil masuk Anda akan ditempatkan di **Waiting Room**.

### Aktivitas di Waiting Room:
1. **Pilih Karakter**: Mengkustomisasi tampilan dan gaya rambut karakter Anda sebelum bertanding.
2. **Periksa Nama**: Pastikan nama/nickname Anda sudah sesuai dan terdaftar di layar.
3. **Bersiap**: Menunggu Host memulai permainan. Ketika Host menekan tombol **Start Game**, Anda akan otomatis dialihkan ke arena gameplay 2D.

---
