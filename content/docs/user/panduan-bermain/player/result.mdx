# Result (Hasil Akhir)

![Tampilan Halaman Result](/images/result.png)

Setelah Anda menyelesaikan semua soal atau waktu habis, layar permainan akan berubah.

### Apa yang Terjadi Selanjutnya?
1. **Waiting Results**: Anda mungkin akan diminta menunggu sejenak sementara server menghitung skor semua pemain.
2. **Layar Hasil**: Anda akan melihat peringkat (ranking) dan total poin yang berhasil Anda kumpulkan di perangkat Anda.
3. **Kembali ke Dashboard**: Setelah melihat hasil, Anda bisa kembali ke halaman awal untuk bergabung dengan ruangan lain atau beristirahat.
