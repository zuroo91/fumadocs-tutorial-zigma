# Login

![Tampilan Halaman Login](/images/login.png)

Untuk mulai bermain atau membuat ruangan di Zigma, Anda perlu melakukan Login terlebih dahulu.

### Langkah-langkah Login:
1. Buka halaman utama aplikasi Zigma.
2. Anda akan melihat layar login yang meminta metode autentikasi.
3. Pilih metode login yang tersedia (misalnya: Google atau Guest).
4. Setelah berhasil login, Anda akan langsung diarahkan ke halaman **Home Page**.
