# Setting (Pengaturan Sesi)

Halaman **Setting** muncul setelah Anda memilih kuis di halaman Select Quiz, baik melalui tombol **Start Quiz** (Host) maupun **Play Now** (Tryout). Di sini Anda dapat menyesuaikan konfigurasi sesi sebelum permainan dimulai.

## Opsi Pengaturan

Pengaturan berikut tersedia di **kedua mode** (Host maupun Tryout):

- **Tingkat Kesulitan (Difficulty)**: Menentukan tingkat kesulitan **peta permainan (map)**, bukan tingkat kesulitan soal kuis. Semakin tinggi difficulty, semakin menantang peta yang dimainkan.
- **Durasi**: Mengatur batas waktu sesi permainan.
- **Jumlah Soal**: Menentukan berapa banyak soal yang akan ditampilkan selama permainan.
- **Sound**: Mengaktifkan atau menonaktifkan suara/musik selama permainan.

## Perbedaan Setting Host vs Setting Tryout

| Fitur | Setting Host | Setting Tryout |
|---|---|---|
| **Pilih Karakter** | ❌ Tidak ada | ✅ Ada |
| **Difficulty** | ✅ Ada | ✅ Ada |
| **Durasi** | ✅ Ada | ✅ Ada |
| **Jumlah Soal** | ✅ Ada | ✅ Ada |
| **Sound** | ✅ Ada | ✅ Ada |

> Satu-satunya perbedaan adalah pada Setting Tryout terdapat fitur **pemilihan karakter** yang tidak ada di Setting Host.

## Setelah Setting Selesai

- **Host** → klik **Lanjut** untuk membuka **Host Lobby** dan menunggu pemain bergabung.
- **Tryout** → klik **Lanjut** untuk langsung masuk ke permainan secara mandiri.
