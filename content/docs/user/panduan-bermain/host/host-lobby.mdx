# Host Lobby

![Tampilan Host Lobby](/images/host-lobby.png)

Di Host Lobby, Anda bertugas sebagai pengelola ruangan sambil menunggu pemain lain (Player) masuk.

### Hal yang Perlu Dilakukan:
1. **Bagikan Kode Room, QR Code, atau Link**: Tampilkan layar Anda agar pemain dapat melihat kode PIN / scan QR Code, atau salin dan bagikan **tautan langsung (link)** room yang tersedia di Host Lobby kepada pemain.
2. **Pantau Pemain**: Anda dapat melihat avatar dan nama-nama pemain yang sudah berhasil bergabung.
3. **Mulai Permainan**: Setelah semua pemain siap dan masuk ke ruangan, klik tombol **Mulai Permainan (Start Game)** untuk memindahkan semua pemain ke fase *Gameplay*.
