# Host Monitor (Progress Permainan)

![Tampilan Host Monitor](/images/host-monitor.png)

Saat permainan berlangsung, layar Host akan menampilkan jalannya permainan (gameplay) dari sudut pandang pemantau.

### Apa yang Ditampilkan?
- **Perkembangan Pemain**: Anda dapat memantau bagaimana pemain bergerak, bertarung, dan menjawab soal kuis secara *real-time*.
- **Status Soal**: Mengetahui progres pengerjaan kuis dari para pemain.

Host tidak ikut bermain, melainkan berperan sebagai pengamat dan pemandu jalannya acara (seperti presenter layar besar).
