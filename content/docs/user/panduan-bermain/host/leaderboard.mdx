# Leaderboard (Klasemen Akhir)
![Tampilan Halaman Leaderboard](/images/leaderboard.jpeg)

Setelah semua soal kuis dijawab atau waktu permainan habis, Host akan diarahkan ke layar **Leaderboard**.

### Fitur Leaderboard:
- **Podium**: Menampilkan 3 pemain dengan skor tertinggi.
- **Klasemen Lengkap**: Menampilkan seluruh peringkat dan skor dari semua pemain.
- **Selesai**: Tombol untuk menutup permainan dan kembali ke Dashboard.
