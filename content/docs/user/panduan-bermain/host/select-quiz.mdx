# Select Quiz (Pilih Kuis)

Halaman **Select Quiz** adalah titik awal untuk memulai permainan di Zigma, baik sebagai Host maupun untuk bermain sendiri melalui Tryout.

![Tampilan Select Quiz](/images/select-quiz.png)

## Cara Memilih Kuis

1. Dari **Home Page**, klik tombol **Host Game**.
2. Anda akan melihat daftar kuis yang tersedia.
3. Klik salah satu kuis untuk melihat detail-nya.

## Dialog Detail Kuis

![Dialog Detail Kuis](/images/dialog-detail.png)

Setelah mengklik sebuah kuis, akan muncul **pop-up / dialog** berisi detail kuis tersebut. Di dalam dialog ini terdapat **dua tombol pilihan**:

### Play Now — Tryout
Memulai kuis secara **mandiri** tanpa membutuhkan pemain lain. Mode ini cocok untuk:
- Latihan atau persiapan sebelum sesi multiplayer.
- Mencoba soal-soal dalam kuis secara santai.

Setelah menekan **Play Now**, Anda akan diarahkan ke halaman **Setting** untuk mengatur detail sesi Tryout sebelum permainan dimulai.

### Start Quiz — Sebagai Host
Membuat **sesi multiplayer baru** sebagai Host. Setelah menekan tombol ini, Anda akan diarahkan ke halaman **Setting** untuk mengatur detail sesi sebelum ruangan dibuat dan pemain lain dapat bergabung.
