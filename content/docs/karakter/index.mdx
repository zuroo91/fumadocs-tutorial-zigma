# Sistem Karakter

Game ini punya 4 tipe karakter yang bisa dipilih pemain. Setiap karakter punya base
stats, skill unik, dan elemen yang berlawanan satu sama lain.

| Karakter | Tipe    | Skill Utama    | Elemen |
| -------- | ------- | -------------- | ------ |
| Warrior  | Tank    | Shield Bash    | Earth  |
| Mage     | DPS     | Fireball       | Fire   |
| Ranger   | Range   | Arrow Rain     | Wind   |
| Healer   | Support | Healing Light  | Light  |

Lihat detail lengkap cara membangun sistem karakter di
[**Studi Kasus: Sistem Karakter**](/docs/games/mind-venture/sistem-karakter).
