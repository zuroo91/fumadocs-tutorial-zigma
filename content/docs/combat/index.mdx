# Sistem Combat

Inti dari game adalah loop **jawab soal → serang lawan**. Setiap jawaban benar
menghasilkan damage yang dihitung dari base attack, skill multiplier, dan defense
lawan.

Lihat implementasi lengkap di
[**Tutorial: Sistem Kuis**](/docs/tutorial/player/sistem-kuis).
