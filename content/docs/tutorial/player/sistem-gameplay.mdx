# Membangun Sistem Gameplay 2D (Phaser 3)

Pada modul ini, kamu akan membangun **`GameScene`** menggunakan Phaser 3 untuk me-render peta 2D bergaya retro pixel, memuat spritesheet karakter berlapis, menangani input keyboard WASD / Virtual Joystick, dan mendeteksi tabrakan dengan rintangan.

---

## Langkah 1: Memuat Aset Sprite & Tilemap (Preload)

Buat file `client/src/scenes/player/GameScene.ts` dan implementasikan metode `preload()`:

```typescript title="client/src/scenes/player/GameScene.ts (Bagian Preload)"
import Phaser from 'phaser';
import { RoomService } from '../../services/room/RoomService';

export class GameScene extends Phaser.Scene {
  private roomService = RoomService.getInstance();
  private playerSprite!: Phaser.Physics.Arcade.Sprite;
  private cursors!: Phaser.Types.InputPlugin.Keyboard.CursorKeys;
  private wasdKeys: any;

  constructor() {
    super({ key: 'GameScene' });
  }

  preload() {
    // 1. Memuat Tilemap JSON & Tileset Gambar
    this.load.image('dungeon_tiles', '/assets/tilesets/dungeon.png');
    this.load.tilemapTiledJSON('map_arena', '/assets/tilemaps/arena.json');

    // 2. Memuat Spritesheet Karakter Dasar & Rambut
    this.load.spritesheet('body_human', '/assets/sprites/character/body.png', {
      frameWidth: 32,
      frameHeight: 32
    });
    this.load.spritesheet('hair_spikey', '/assets/sprites/character/hair_spikey.png', {
      frameWidth: 32,
      frameHeight: 32
    });

    // 3. Memuat Monster & Peti
    this.load.spritesheet('monster_skeleton', '/assets/sprites/enemies/skeleton.png', {
      frameWidth: 32,
      frameHeight: 32
    });
    this.load.spritesheet('chest_gold', '/assets/sprites/items/chest.png', {
      frameWidth: 32,
      frameHeight: 32
    });
  }
```

## Langkah 2: Menginisialisasi Peta & Lapisan Tabrakan (Create)

Tambahkan pembuatan map dan physics colliders pada metode `create()`:

```typescript title="client/src/scenes/player/GameScene.ts (Bagian Create)"
  create() {
    // 1. Inisialisasi Tilemap
    const map = this.make.tilemap({ key: 'map_arena' });
    const tileset = map.addTilesetImage('DungeonTiles', 'dungeon_tiles')!;
    
    map.createLayer('GroundLayer', tileset, 0, 0);
    const obstaclesLayer = map.createLayer('ObstaclesLayer', tileset, 0, 0);
    obstaclesLayer?.setCollisionByProperty({ collides: true });

    // 2. Inisialisasi Karakter Player
    this.playerSprite = this.physics.add.sprite(200, 200, 'body_human');
    this.playerSprite.setCollideWorldBounds(true);
    this.playerSprite.setSize(16, 16).setOffset(8, 16); // Sesuaikan bounding box hitbox

    if (obstaclesLayer) {
      this.physics.add.collider(this.playerSprite, obstaclesLayer);
    }

    // 3. Konfigurasi Kamera Mengikuti Karakter
    this.cameras.main.startFollow(this.playerSprite, true, 0.1, 0.1);
    this.cameras.main.setZoom(2.0);
    this.cameras.main.setBounds(0, 0, map.widthInPixels, map.heightInPixels);

    // 4. Konfigurasi Input Keyboard
    this.cursors = this.input.keyboard!.createCursorKeys();
    this.wasdKeys = this.input.keyboard!.addKeys({
      up: Phaser.Input.Keyboard.KeyCodes.W,
      down: Phaser.Input.Keyboard.KeyCodes.S,
      left: Phaser.Input.Keyboard.KeyCodes.A,
      right: Phaser.Input.Keyboard.KeyCodes.D,
      attack: Phaser.Input.Keyboard.KeyCodes.SPACE
    });
  }
```

## Langkah 3: Mengelola Loop Input & Transmisi Pergerakan (Update)

Implementasikan penanganan input di metode `update()`:

```typescript title="client/src/scenes/player/GameScene.ts (Bagian Update)"
  update() {
    const speed = 150;
    let vx = 0;
    let vy = 0;

    if (this.cursors.left.isDown || this.wasdKeys.left.isDown) vx = -speed;
    else if (this.cursors.right.isDown || this.wasdKeys.right.isDown) vx = speed;

    if (this.cursors.up.isDown || this.wasdKeys.up.isDown) vy = -speed;
    else if (this.cursors.down.isDown || this.wasdKeys.down.isDown) vy = speed;

    // Normalisasi kecepatan diagonal
    if (vx !== 0 && vy !== 0) {
      vx *= 0.7071;
      vy *= 0.7071;
    }

    this.playerSprite.setVelocity(vx, vy);

    // Kirim pembaruan posisi ke server Colyseus jika karakter bergerak
    if (vx !== 0 || vy !== 0) {
      this.roomService.sendMovement(this.playerSprite.x, this.playerSprite.y);
    }
  }
}
```

* **File dibuat**: `client/src/scenes/player/GameScene.ts`
* **Fungsi**: Mengelola visualisasi dunia game 2D dan menangkap input pemain secara responsif.
