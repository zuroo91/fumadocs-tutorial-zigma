# Mode Multipemain (Player Client)

Pada sisi pemain, koneksi multiplayer ke server Colyseus dikelola melalui instance `Room` dari library **`colyseus.js`**. 

Klien tidak melakukan polling HTTP secara berkala, melainkan menerima siaran perubahan state (*delta updates*) secara langsung melalui protokol WebSocket.

---

## 1. Menghubungkan Klien ke Room Colyseus

Ketika pemain menyelesaikan proses validasi di halaman `/join`, fungsi `joinById` dipanggil untuk menyambungkan klien ke room permainan:

```typescript title="Koneksi Klien ke Server Colyseus"
import { Client } from 'colyseus.js';

// Inisialisasi klien Colyseus
const client = new Client(import.meta.env.VITE_SERVER_URL || 'http://localhost:2567');

const joinOptions = {
    name: nickname,
    userId: profile.id,
    avatarUrl: profile.avatar_url || "",
    hairId: savedHairId ? parseInt(savedHairId) : 0,
    isHost: false
};

// Bergabung ke room yang sudah dibuat oleh Host
const room = await client.joinById(targetRoom.roomId, joinOptions);

// Simpan identitas sesi ke SessionStore
SessionStore.set('currentSessionId', room.sessionId, 'player');
SessionStore.set('currentReconnectionToken', room.reconnectionToken, 'player');
localStorage.setItem('currentRoomCode', roomCode);
```

## 2. Event Listener Entitas Pemain di GameScene

Di dalam scene permainan, klien mendengarkan perubahan daftar pemain yang ada di room:

```typescript title="Event Listener Entitas Pemain"
// 1. Pemain baru masuk ke arena
this.room.state.players.onAdd((player: any, sessionId: string) => {
    if (sessionId === this.mySessionId) {
        // Inisialisasi avatar pemain lokal
        this.currentPlayer = this.createPlayerContainer(player);
        this.cameras.main.startFollow(this.currentPlayer, true, 0.2, 0.2);
    } else {
        // Inisialisasi avatar pemain lain
        const otherPlayer = this.createPlayerContainer(player);
        this.playerEntities[sessionId] = otherPlayer;
    }

    // Dengarkan perubahan koordinat pemain lain
    player.onChange(() => {
        const entity = this.playerEntities[sessionId];
        if (entity) {
            entity.setData('targetX', player.x);
            entity.setData('targetY', player.y);
        }
    });
});

// 2. Pemain keluar atau terputus
this.room.state.players.onRemove((player: any, sessionId: string) => {
    const entity = this.playerEntities[sessionId];
    if (entity) {
        entity.destroy();
        delete this.playerEntities[sessionId];
    }
});
```

## 3. Pengiriman Input Pergerakan (*Throttled Input*)

Untuk mengoptimalkan penggunaan jaringan dan mencegah banjir paket (*packet flooding*), input koordinat pemain lokal dikirim dengan batas interval waktu (`networkSendRate` = 100ms):

```typescript title="Pengiriman Input Pergerakan Throttled"
update(time: number, delta: number) {
    if (!this.room || !this.isGameReady || this.isAttacking) return;

    // Hitung posisi baru berdasarkan keyboard, joystick, atau click-to-move
    const newX = this.currentPlayer.x + (velocity.x * speed * (delta / 1000));
    const newY = this.currentPlayer.y + (velocity.y * speed * (delta / 1000));

    // Validasi rintangan dinding (wall-sliding)
    this.movePlayerWithCollision(newX, newY);

    // Kirim pembaruan posisi ke server Colyseus setiap 100ms
    const now = Date.now();
    if (now - this.lastNetworkSendTime >= this.networkSendRate) {
        this.lastNetworkSendTime = now;
        this.room.send("movePlayer", {
            x: Math.round(this.currentPlayer.x),
            y: Math.round(this.currentPlayer.y)
        });
    }
}
```

## 4. Sinkronisasi Countdown & Akhir Game

Klien mendengarkan event waktu dan status akhir permainan secara otomatis dari server:

```typescript title="Sinkronisasi Listener Waktu & Game Ended"
// A. Hitung mundur 10 detik di awal permainan
this.room.state.listen("countdown", (val: number) => {
    if (val > 0) {
        TransitionManager.setCountdownText(val.toString());
        AudioManager.getInstance().playCountdownSFX();
    } else if (val === 0) {
        TransitionManager.setCountdownText("GO!");
        this.isGameReady = true; // Buka kunci kontrol pemain
    }
});

// B. Notifikasi akhir permainan dari server
this.room.onMessage("gameEnded", (data: { rankings: any[] }) => {
    this.isEnding = true;
    TransitionManager.close(() => {
        // Berpindah ke ResultManager untuk melihat kartu skor personal
        import('../results/page').then((m) => {
            const manager = new m.ResultManager();
            manager.start({ room: this.room, leaderboardData: data.rankings });
        });
    });
});
```
