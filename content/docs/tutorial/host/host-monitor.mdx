# Membangun Host Live Spectator & Progress Monitor

Pada modul ini, kamu akan membangun **`HostProgressScene`** yang bertindak sebagai layar live spectator. Scene ini menggabungkan rendering peta 2D Phaser 3 untuk melihat seluruh pemain bergerak secara real-time dan bilah overlay HTML untuk memantau progres pengerjaan soal setiap siswa.

## Langkah 1: Membangun Scene Phaser Spectator (HostProgressScene)

Buat file `client/src/scenes/host/HostProgressScene.ts`:

```typescript title="client/src/scenes/host/HostProgressScene.ts"
import Phaser from 'phaser';
import { RoomService } from '../../services/room/RoomService';
import type { Room } from 'colyseus.js';

export class HostProgressScene extends Phaser.Scene {
  private roomService = RoomService.getInstance();
  private room: Room | null = null;
  private playerSprites: { [id: string]: Phaser.GameObjects.Sprite } = {};

  constructor() {
    super({ key: 'HostProgressScene' });
  }

  create() {
    this.room = this.roomService.getActiveRoom();
    if (!this.room) return;

    // 1. Memuat Peta & Tilemap Arena
    const map = this.make.tilemap({ key: 'arena_map' });
    const tileset = map.addTilesetImage('tileset_dungeon', 'tiles');
    map.createLayer('Ground', tileset!, 0, 0);
    map.createLayer('Obstacles', tileset!, 0, 0);

    // 2. Listener Sinkronisasi Pergerakan Pemain
    this.room.state.players.onAdd((player, sessionId) => {
      if (!player.isHost) {
        const sprite = this.add.sprite(player.x, player.y, `body_human`);
        this.playerSprites[sessionId] = sprite;

        // Listener perubahan posisi pemain
        player.onChange(() => {
          sprite.setPosition(player.x, player.y);
        });
      }
    });

    this.room.state.players.onRemove((player, sessionId) => {
      if (this.playerSprites[sessionId]) {
        this.playerSprites[sessionId].destroy();
        delete this.playerSprites[sessionId];
      }
    });

    // 3. Render Overlay Bilah Progres Siswa
    this.createProgressOverlay();
  }

  private createProgressOverlay() {
    const overlay = document.createElement('div');
    overlay.id = 'host-progress-overlay';
    overlay.className = 'fixed top-4 right-4 w-80 bg-gray-900/90 border border-gray-800 rounded-2xl p-4 text-white z-20 max-h-[80vh] overflow-y-auto';

    overlay.innerHTML = `
      <div class="flex justify-between items-center mb-3">
        <h4 class="font-bold text-sm text-teal-400">Progres Kuis Peserta</h4>
        <button id="btn-end-game" class="px-3 py-1 bg-red-600 hover:bg-red-500 rounded-lg text-xs font-bold transition">
          End Game
        </button>
      </div>
      <div id="progress-list" class="space-y-2"></div>
    `;

    document.body.appendChild(overlay);

    document.getElementById('btn-end-game')?.addEventListener('click', () => {
      this.room?.send("HOST_END_GAME");
      window.location.hash = `#/host/${this.room?.state.roomCode}/leaderboard`;
    });

    this.updateProgressList();
  }

  private updateProgressList() {
    const list = document.getElementById('progress-list');
    if (!list || !this.room) return;

    list.innerHTML = '';
    this.room.state.players.forEach((player) => {
      if (!player.isHost) {
        const item = document.createElement('div');
        item.className = 'text-xs bg-gray-800 p-2 rounded-lg';
        const percent = Math.min(100, Math.round((player.answeredCount / 10) * 100));

        item.innerHTML = `
          <div class="flex justify-between mb-1">
            <span class="font-semibold truncate">${player.nickname}</span>
            <span class="text-teal-300">${player.score} Pts (${player.answeredCount}/10)</span>
          </div>
          <div class="w-full bg-gray-700 h-1.5 rounded-full overflow-hidden">
            <div class="bg-teal-400 h-full transition-all duration-300" style="width: ${percent}%"></div>
          </div>
        `;
        list.appendChild(item);
      }
    });
  }
}
```

* **File dibuat**: `client/src/scenes/host/HostProgressScene.ts`
* **Fungsi**: Memantau posisi visual seluruh karakter di arena dan merender bilah capaian kuis secara dinamis.
