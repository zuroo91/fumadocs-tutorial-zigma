# Membangun Sistem Penilaian & Hadiah (Scoring & Rewards)

Sistem penilaian Zigma bersifat **authoritative server**: seluruh perhitungan skor dan validasi bonus waktu dilakukan secara aman di dalam `GameRoom.ts` untuk mencegah manipulasi nilai dari sisi klien.

---

## Langkah 1: Mengimplementasikan Formula Penilaian di Server

Di `server/src/rooms/GameRoom.ts`, tambahkan handler pesan `SUBMIT_ANSWER` untuk mengevaluasi ketepatan jawaban dan menghitung bonus waktu:

```typescript title="server/src/rooms/GameRoom.ts (Logika Penilaian)"
this.onMessage("SUBMIT_ANSWER", (client, data: { questionId: string; selectedOption: string; timeRemainingRatio: number }) => {
  const player = this.state.players.get(client.sessionId);
  if (!player || this.state.status !== "PLAYING") return;

  const question = this.quizQuestions.find(q => q.id === data.questionId);
  if (!question) return;

  const isCorrect = question.correctAnswer.trim().toLowerCase() === data.selectedOption.trim().toLowerCase();
  
  if (isCorrect) {
    // 1. Poin dasar per soal (Rentang total 100 poin)
    const basePoints = Math.round(100 / Math.max(1, this.quizQuestions.length));
    
    // 2. Bonus kecepatan (Speed Bonus maksimal 20% tambahan berdasarkan sisa timer)
    const speedBonus = Math.round(basePoints * 0.2 * Math.max(0, data.timeRemainingRatio));
    
    player.score += (basePoints + speedBonus);
  }

  player.answeredCount += 1;

  // Kirim feedback personal ke klien yang menjawab
  client.send("ANSWER_RESULT", {
    isCorrect,
    correctAnswer: question.correctAnswer,
    currentScore: player.score
  });

  // Periksa apakah semua pemain telah menyelesaikan seluruh soal
  this.checkGameCompletion();
});
```

* **Fungsi**: Menghitung poin secara terpusat dengan mempertimbangkan kecepatan respon siswa.

## Langkah 2: Mengimplementasikan Mekanika Peti Harta Karun (Chest Buffs)

Tambahkan skema dan logika interaksi peti di `server/src/rooms/GameRoom.ts`:

```typescript title="server/src/rooms/GameRoom.ts (Interaksi Peti)"
this.onMessage("OPEN_CHEST", (client, data: { chestId: string }) => {
  const player = this.state.players.get(client.sessionId);
  if (!player) return;

  // Berikan buff acak (Bonus Poin atau Peningkatan Kecepatan)
  const isSpeedBuff = Math.random() > 0.5;

  if (isSpeedBuff) {
    client.send("APPLY_BUFF", { type: "SPEED_BOOST", durationMs: 5000 });
  } else {
    player.score += 5; // Tambahan 5 poin ekstra
    client.send("APPLY_BUFF", { type: "BONUS_SCORE", points: 5 });
  }
});
```

## Langkah 3: Menangani Penyelesaian Sesi Otomatis

Tambahkan metode pemeriksaan penyelesaian kuis di `server/src/rooms/GameRoom.ts`:

```typescript title="server/src/rooms/GameRoom.ts (Deteksi Selesai)"
private checkGameCompletion() {
  let allFinished = true;

  this.state.players.forEach((player) => {
    if (!player.isHost && player.answeredCount < this.quizQuestions.length) {
      allFinished = false;
    }
  });

  if (allFinished && this.state.players.size > 1) {
    this.state.status = "FINISHED";
    this.broadcast("GAME_FINISHED", {
      reason: "ALL_PLAYERS_COMPLETED"
    });
  }
}
```

Dengan langkah ini, seluruh siklus penilaian telah terintegrasi penuh dan terlindungi dari manipulasi klien.
