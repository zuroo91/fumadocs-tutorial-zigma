# Homepage & Dashboard

Halaman utama Zigma bertindak sebagai gerbang navigasi utama bagi pengguna setelah melewati pemeriksaan autentikasi.

Berbeda dengan aplikasi React biasa, Zigma menggunakan **TypeScript DOM bootstrap** yang memuat overlay HTML/TailwindCSS di atas canvas Phaser 3.

---

## 1. Bootstrap Utama Aplikasi

Fungsi `bootstrap()` bertanggung jawab atas inisialisasi awal seluruh aplikasi:

1. **Sinkronisasi Bahasa (`initLanguageSync`)**: Membaca preferensi bahasa pengguna (`id`, `en`, `ar`) dan mengatur arah antarmuka (LTR atau RTL).
2. **Penanganan OAuth Callback**: Memeriksa parameter token OAuth pada URL.
3. **Pemeriksaan Sesi Autentikasi**:
   * Jika belum login (`!isAuth`), sistem merender `LoginUI` dan menginisialisasi `LoginManager`.
   * Jika sudah terautentikasi, sistem merender antarmuka lobi (`LobbyUI`, `CreateRoomUI`, `QuizSelectionUI`, dll.) dan menginisialisasi `LobbyManager`.

```typescript title="Bootstrap Inisialisasi Aplikasi"
// Periksa status autentikasi pemain
const isAuth = await authService.isAuthenticated();

if (!isAuth) {
    const { LoginUI } = await import('./scenes/login/ui');
    const { LoginManager } = await import('./scenes/login/page');
    LoginUI.render();
    const loginManager = new LoginManager();
    await loginManager.init();
} else {
    // Muat UI lobi secara paralel
    const [
        { LobbyUI },
        { LobbyManager },
        { CreateRoomUI },
        { QuizSelectionUI },
        { QuizSettingsUI },
    ] = await Promise.all([
        import('./scenes/lobby/ui'),
        import('./scenes/lobby/page'),
        import('./scenes/lobby/create-room-ui'),
        import('./scenes/host/selectquiz/ui'),
        import('./scenes/host/[roomCode]/quizsetting/ui'),
    ]);

    // Render komponen DOM ke dalam container #app
    LobbyUI.render();
    CreateRoomUI.render();
    QuizSelectionUI.render();
    QuizSettingsUI.render();

    const lobbyManager = new LobbyManager();
    await lobbyManager.init();
}
```

## 2. Menu Utama & Navigasi (`LobbyManager.ts`)

![Tampilan Beranda & Dashboard Zigma](/images/homepage.png)

Class `LobbyManager` mengelola interaksi di beranda:

1. **Tampilan Profil Pengguna**:
   * Menampilkan nama panggilan (*nickname*) atau nama lengkap dari profil Supabase.
   * Menampilkan avatar pemain. Jika gambar gagal dimuat, sistem menampilkan inisial huruf nama secara otomatis.
2. **Opsi Host Game**:
   * Membuka modal pemilihan kuis (`SelectQuizManager`).
   * Mengatur parameter ruangan (waktu, tingkat kesulitan, map).
3. **Opsi Join Game**:
   * **Input PIN 6-digit**: Pemain mengetikkan kode unik ruangan secara langsung.
   * **Scan QR Code**: Pemain membuka pemindai kamera via library `html5-qrcode` untuk bergabung tanpa perlu mengetik manual.
   * **Auto-Join via URL**: Jika pemain membuka tautan dengan format `/join/:roomCode` atau parameter `?room=...`, sistem akan memproses auto-join secara otomatis.

## 3. Struktur Rute Navigasi Zigma

Zigma menggunakan utility router kustom (`Router.ts`) yang mengatur transisi halaman tanpa reload (*Single Page Application*):

| Menu / Aksi | Rute URL | Pengelola Scene / Manager |
|---|---|---|
| Beranda / Lobi Utama | `/` | `LobbyManager` |
| Login Akun | `/login` | `LoginManager` |
| Pemilihan Kuis Host | `/host/select` | `SelectQuizManager` |
| Pengaturan Room Host | `/host/[roomCode]/settings` | `QuizSettingManager` |
| Ruang Tunggu Host | `/host/[roomCode]/lobby` | `HostWaitingRoomScene` |
| Spectator Monitor Host | `/host/[roomCode]/progress` | `HostProgressScene` |
| Ruang Tunggu Pemain | `/player/[roomCode]/waiting` | `PlayerWaitingRoomManager` |
| Arena Permainan 2D | `/player/[roomCode]/game` | `GameScene` |
| Kartu Hasil Pemain | `/player/[roomCode]/result` | `ResultManager` |
| Leaderboard Akhir | `/host/[roomCode]/leaderboard` | `HostLeaderboardManager` |
| Bot Load Testing | `/test` | `BotSimulatorManager` |

Lanjutkan ke [Host: Create Room →](/docs/tutorial/host/create-room) atau [Join Session →](/docs/tutorial/join/join-session).
