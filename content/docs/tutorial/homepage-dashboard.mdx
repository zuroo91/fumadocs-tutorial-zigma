# Membangun Homepage & Kustomisasi Avatar

Halaman beranda Zigma dibangun dengan menggabungkan **rendering canvas Phaser 3** untuk background animasi dan **overlay DOM HTML/TailwindCSS** untuk formulir input interaktif.

![Tampilan Beranda Zigma](/images/homepage.png)

---

## Langkah 1: Mendefinisikan Opsi Gaya Rambut Karakter

Buat file `client/src/constants/character.ts` untuk mendefinisikan seluruh varian rambut yang dapat dipilih oleh pemain:

```typescript title="client/src/constants/character.ts"
export interface HairOption {
  id: string;
  name: string;
  spriteKey: string;
  previewUrl: string;
}

export const HAIR_OPTIONS: HairOption[] = [
  { id: 'BOWL', name: 'Bowl Hair', spriteKey: 'hair_bowl', previewUrl: '/images/karakter/bowlhair.png' },
  { id: 'CURLY', name: 'Curly Hair', spriteKey: 'hair_curly', previewUrl: '/images/karakter/curlyhair.png' },
  { id: 'LONG', name: 'Long Hair', spriteKey: 'hair_long', previewUrl: '/images/karakter/longhair.png' },
  { id: 'MOP', name: 'Mop Hair', spriteKey: 'hair_mop', previewUrl: '/images/karakter/mophair.png' },
  { id: 'SHORT', name: 'Short Hair', spriteKey: 'hair_short', previewUrl: '/images/karakter/shorthair.png' },
  { id: 'SPIKEY', name: 'Spikey Hair', spriteKey: 'hair_spikey', previewUrl: '/images/karakter/spikeyhair.png' },
];
```

* **File dibuat**: `client/src/constants/character.ts`
* **Fungsi**: Menstandarisasi kunci sprite animasi rambut yang akan dimuat oleh engine Phaser 3.

## Langkah 2: Mengonfigurasi Multi-Bahasa (i18n)

Buat file `client/src/i18n.ts` menggunakan library `i18next` untuk mendukung bahasa Indonesia, Inggris, dan Arab:

```typescript title="client/src/i18n.ts"

i18n.init({
```

## Langkah 3: Membangun Komponen DOM Homepage Overlay

Buat file `client/src/components/HomeOverlay.ts` untuk merender elemen HTML di atas canvas game:

```typescript title="client/src/components/HomeOverlay.ts"
import { HAIR_OPTIONS } from '../constants/character';

export class HomeOverlay {
  private container: HTMLDivElement;
  private selectedHairIndex = 0;

  constructor(onJoin: (nickname: string, pin: string, hair: string) => void, onHost: () => void) {
    this.container = document.createElement('div');
    this.container.id = 'home-overlay';
    this.container.className = 'absolute inset-0 flex items-center justify-center pointer-events-auto z-10';

    this.render(onJoin, onHost);
    document.body.appendChild(this.container);
  }

  private render(onJoin: Function, onHost: Function) {
    const hair = HAIR_OPTIONS[this.selectedHairIndex];

    this.container.innerHTML = `
      <div class="bg-gray-900/90 backdrop-blur-md p-8 rounded-2xl shadow-2xl border border-purple-500/30 w-full max-w-md text-white text-center">
        <h1 class="text-3xl font-extrabold text-transparent bg-clip-text bg-gradient-to-r from-purple-400 to-teal-300 mb-6">ZIGMA ARCADE</h1>
        
        <!-- Preview Karakter -->
        <div class="flex items-center justify-center gap-4 mb-6">
          <button id="btn-prev-hair" class="px-3 py-1 bg-gray-800 rounded-lg text-lg">◀</button>
          <div class="flex flex-col items-center">
            <img src="${hair.previewUrl}" alt="${hair.name}" class="w-16 h-16 object-contain image-pixelated" />
            <span class="text-xs text-gray-400 mt-1">${hair.name}</span>
          </div>
          <button id="btn-next-hair" class="px-3 py-1 bg-gray-800 rounded-lg text-lg">▶</button>
        </div>

        <!-- Form Input -->
        <input id="input-nickname" type="text" placeholder="Masukkan Nickname" class="w-full px-4 py-3 bg-gray-800 border border-gray-700 rounded-xl mb-3 text-white focus:outline-none focus:border-purple-500" maxlength="15" />
        <input id="input-pin" type="text" placeholder="PIN Room (6 Digit)" class="w-full px-4 py-3 bg-gray-800 border border-gray-700 rounded-xl mb-4 text-white text-center tracking-widest font-mono text-lg focus:outline-none focus:border-purple-500" maxlength="6" />

        <button id="btn-join" class="w-full py-3 bg-gradient-to-r from-purple-600 to-indigo-600 hover:from-purple-500 hover:to-indigo-500 font-bold rounded-xl shadow-lg transition duration-200 mb-3">
          Join Room
        </button>

        <button id="btn-host" class="w-full py-2 bg-gray-800 hover:bg-gray-700 text-sm text-gray-300 rounded-xl border border-gray-700 transition">
          Host Game
        </button>
      </div>
    `;

    this.attachEvents(onJoin, onHost);
  }

  private attachEvents(onJoin: Function, onHost: Function) {
    document.getElementById('btn-prev-hair')?.addEventListener('click', () => {
      this.selectedHairIndex = (this.selectedHairIndex - 1 + HAIR_OPTIONS.length) % HAIR_OPTIONS.length;
      this.render(onJoin, onHost);
    });

    document.getElementById('btn-next-hair')?.addEventListener('click', () => {
      this.selectedHairIndex = (this.selectedHairIndex + 1) % HAIR_OPTIONS.length;
      this.render(onJoin, onHost);
    });

    document.getElementById('btn-join')?.addEventListener('click', () => {
      const name = (document.getElementById('input-nickname') as HTMLInputElement)?.value.trim();
      const pin = (document.getElementById('input-pin') as HTMLInputElement)?.value.trim();
      const hair = HAIR_OPTIONS[this.selectedHairIndex].id;
      if (name && pin.length === 6) onJoin(name, pin, hair);
    });

    document.getElementById('btn-host')?.addEventListener('click', () => onHost());
  }

  public destroy() {
    this.container.remove();
  }
}
```

* **File dibuat**: `client/src/components/HomeOverlay.ts`
* **Fungsi**: Menyediakan antarmuka interaktif yang mudah dihubungkan ke scene Phaser dan router game.
