# Mulai Sekarang

Selamat datang di panduan teknis **Zigma**! Di bagian ini kamu akan mempersiapkan environment dan workspace monorepo untuk menjalankan game kuis multiplayer real-time 2D.

<Callout type="info">
  Estimasi waktu: **15–30 menit** untuk setup environment, konfigurasi file `.env`, dan menjalankan development server.
</Callout>

## Gambaran Umum Zigma & Cara Kerja

Zigma adalah game *Educational 2D Top-Down Multiplayer Quiz Arcade* berbasis Web dari platform GameForSmart (`gameforsmart.com`). Game ini memadukan aksi petualangan 2D retro pixel dengan kuis edukatif:

* **Konsep**: Host membuat room kuis, menentukan batas waktu dan jumlah soal. Pemain bergabung menggunakan kode PIN 6-digit atau scan QR Code.
* **Cara Kerja**: Pemain mengendalikan avatar Human 2D untuk mengejar monster (skeleton & goblin) yang membawa kuis. Begitu didekati dan ditebas, modal kuis interaktif muncul. Menjawab dengan benar mengalahkan monster dan menambah skor, sementara peti harta karun (*chests*) memberikan buff kecepatan dan pemulihan nilai.

## Prasyarat Sistem

Pastikan tools berikut sudah terpasang di perangkat kamu:

* **Node.js** versi LTS (>= 18.0.0) — [download](https://nodejs.org/)
* **Git** untuk version control
* **Redis Server** (port `6379`) — untuk clustering matchmaking Colyseus
* **Proyek Supabase** — URL & Service Role Key untuk database PostgreSQL
* **Code Editor** — Rekomendasi: Visual Studio Code

## Quick Start

```bash
# 1. Clone repository
git clone https://gitlab.com/your-org/MultiplayerGameQuiz.git
cd MultiplayerGameQuiz

# 2. Install seluruh dependency monorepo (client, server, shared)
npm install

# 3. Salin file environment konfigurasi
cp server/.env.example server/.env
cp client/.env.example client/.env

# 4. Jalankan client dan server secara serentak
npm run dev
```

Server Colyseus akan berjalan di `http://localhost:2567`, dan client Vite akan terbuka di `http://localhost:5173`.

## Struktur Monorepo

```text
MultiplayerGameQuiz/
├── package.json                         # Config root monorepo & script utama
├── shared/
│   └── state.ts                         # Definisi schema Colyseus (GameState, Player, Enemy, Chest, etc.)
├── server/
│   ├── package.json                     # Dependency server (Colyseus, Express, Redis, Supabase)
│   └── src/
│       ├── server.ts                    # Entrypoint server Express + Colyseus WebSocket + Redis setup
│       ├── rooms/
│       │   ├── GameRoom.ts              # Logika room utama, lifecycle, handler pesan WS, & AI musuh
│       │   └── GameState.ts             # Re-export schema dari shared/state.ts
│       ├── utils/
│       │   ├── MapParser.ts             # Parser tilemap Tiled untuk spawn zone & rintangan map
│       │   └── supabase.ts              # Integrasi client Supabase backend
│       └── routes/
│           └── sync-results.ts          # API Endpoint penyimpanan hasil kuis
└── client/
    ├── package.json                     # Dependency client (Phaser, Colyseus.js, Vite, Tailwind)
    ├── bot.html                         # Interface HTML simulator bot test
    └── src/
        ├── main.ts                      # Entrypoint client, router autentikasi, & UI DOM bootstrap
        ├── game.ts                      # Konfigurasi Phaser 3 Game Instance & registrasi Scene
        ├── services/
        │   └── room/RoomService.ts      # Client service penghubung Colyseus WebSocket
        └── scenes/
            ├── host/
            │   └── [roomCode]/
            │       ├── lobby/page.ts    # Scene waiting room host
            │       └── progress/page.ts # Scene pantauan progres siswa secara real-time
            ├── player/
            │   └── [roomCode]/
            │       └── game/page.ts     # Scene gameplay 2D utama player (render map & sprite)
            └── test/
                └── BotSimulatorManager.ts # Simulator bot load testing
```
