# Mulai Sekarang

Selamat datang di build guide **Zigma**! Di bagian ini kamu akan
mempersiapkan environment dan project skeleton untuk mulai membangun game kuis RPG
multiplayer.

<Callout type="info">
  Estimasi waktu: **30 menit** untuk setup awal, lalu **4-6 minggu** untuk MVP
  lengkap dengan multiplayer real-time.
</Callout>

## Gambaran  Umum Zigma & Cara Kerja

Zigma adalah game *Educational 2D Top-Down Multiplayer Quiz Arcade RPG* berbasis Web. Game ini menggabungkan 
mekanisme aksi 2D (avatar, musuh berpatroli/melarikan diri, chest bonus) dengan kuis edukatif.

- **Konsep**: Host membuat room kuis dan menentukan aturan. Player bergabung menggunakan kode unik (roomCode).
- **Cara Kerja**: Player mengontrol avatar 2D untuk mengejar musuh (skeleton/goblin) yang membawa kuis. Saat berinteraksi, 
  modal kuis muncul. Menjawab dengan benar mengalahkan musuh, memberikan poin, dan memperbarui leaderboard real-time.


## Prasyarat

Pastikan tools berikut sudah terpasang di *devices* kamu:

- **Node.js** versi LTS (≥ 18) — [download](https://nodejs.org/)
- **Git** untuk version control
- **Akun Firebase** gratis (Spark plan) untuk Auth, Firestore, dan Hosting
- **Code editor** — rekomendasi: VS Code dengan ekstensi ESLint + Prettier

## Quick Start

```bash
# 1. Buat project baru
mkdir nama project kamu && cd nama project kamu
npm init -y

# 2. Install dependencies utama
npm install react react-dom react-router-dom
npm install firebase
npm install socket.io socket.io-client
npm install axios

# 3. Install dev dependencies
npm install -D vite @vitejs/plugin-react
```

## Struktur Project

```text
MultiplayerGameQuiz/
├── package.json                         # Config root monorepo & script utama
├── shared/
│   └── state.ts                         # Definisi schema Colyseus (GameState, Player, Enemy, Chest, etc.)
├── server/
│   ├── package.json                     # Dependency server (Colyseus, Express, Redis, Supabase)
│   └── src/
│       ├── server.ts                    # Entrypoint server Express + Colyseus WebSocket + Redis setup
│       ├── rooms/
│       │   ├── GameRoom.ts              # Logika room utama, lifecycle, handler pesan WS, & AI musuh
│       │   └── GameState.ts             # Re-export schema dari shared/state.ts
│       ├── utils/
│       │   ├── MapParser.ts             # Parser tilemap Tiled untuk spawn zone & rintangan map
│       │   └── supabase.ts              # Integrasi client Supabase backend
│       └── routes/
│           └── sync-results.ts          # API Endpoint penyimpanan hasil kuis
└── client/
    ├── package.json                     # Dependency client (Phaser, Colyseus.js, Vite, Tailwind)
    ├── bot.html                         # Interface HTML simulator bot test
    └── src/
        ├── main.ts                      # Entrypoint client, router autentikasi, & UI DOM bootstrap
        ├── game.ts                      # Konfigurasi Phaser 3 Game Instance & registrasi Scene
        ├── services/
        │   └── room/RoomService.ts      # Client service penghubung Colyseus WebSocket
        └── scenes/
            ├── host/
            │   └── [roomCode]/
            │       ├── lobby/page.ts    # Scene waiting room host
            │       └── progress/page.ts # Scene pantauan progres siswa secara real-time
            ├── player/
            │   └── [roomCode]/
            │       └── game/page.ts     # Scene gameplay 2D utama player (render map & sprite)
            └── test/
                └── BotSimulatorManager.ts # Simulator bot load testing
```
