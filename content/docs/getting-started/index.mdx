# Mulai Sekarang

Halaman ini memandu kamu untuk menyiapkan lingkungan pengembangan dan menginisialisasi project game **Zigma** dari awal (*from scratch*). Seluruh konfigurasi dan direktori project dibuat secara bertahap tanpa perlu melakukan clone dari repository yang sudah jadi.

<Callout type="info">
  Estimasi waktu setup awal: **15–20 menit** untuk instalasi tools, inisialisasi workspace, konfigurasi file `.env`, dan menginstal dependensi.
</Callout>

---

## Prasyarat Sistem & Instalasi

Sebelum membuat project, pastikan seluruh kebutuhan sistem dan tools berikut sudah terpasang dan siap digunakan:

* **Node.js (LTS $\ge$ 18.0.0) & npm** — Runtime JavaScript untuk menjalankan backend Colyseus/Express dan mengelola paket dependensi. Unduh dari [nodejs.org](https://nodejs.org/) dan verifikasi dengan `node -v` serta `npm -v`.
* **Git** — Version control untuk pelacakan kode sumber. Unduh dari [git-scm.com](https://git-scm.com/) dan verifikasi dengan `git --version`.
* **Redis Server (Port 6379)** — Penyimpan state sesi room (*Presence Driver*) untuk Colyseus. Pasang via Memurai/WSL 2/Docker di Windows, atau package manager (`redis-server` / `brew install redis`) di Linux/macOS. Verifikasi dengan `redis-cli ping` $\rightarrow$ `PONG`.
* **Akun & Project Supabase** — Layanan database PostgreSQL dan autentikasi SSO. Buat project baru di [supabase.com](https://supabase.com/) lalu catat Project URL, Anon Key (client), dan Service Role Key (server) dari menu *Project Settings → API*.
* **Code Editor** — Editor pengembangan kode seperti Visual Studio Code dengan ekstensi rekomendasi *ESLint*, *Prettier*, dan *Tailwind CSS IntelliSense*.

## Inisialisasi Project

Langkah inisialisasi struktur workspace project Zigma dari terminal:

**1. Membuat Direktori Project**
```bash
mkdir MultiplayerGameQuiz
cd MultiplayerGameQuiz
```

**2. Inisialisasi Root package.json (npm Workspaces)**
Buat file `package.json` di root direktori untuk menghubungkan ketiga bagian workspace (`client`, `server`, dan `shared`):

```json title="package.json"
{
  "name": "zigma-project",
  "version": "1.0.0",
  "private": true,
  "workspaces": [
    "client",
    "server",
    "shared"
  ],
  "scripts": {
    "dev": "concurrently \"npm run dev:client\" \"npm run dev:server\"",
    "dev:client": "npm run dev --prefix client",
    "dev:server": "npm run dev --prefix server",
    "build": "npm run build --prefix client && npm run build --prefix server",
    "start": "npm start --prefix server"
  },
  "devDependencies": {
    "concurrently": "^8.2.2"
  },
  "engines": {
    "node": ">=18.0.0"
  }
}
```

**3. Membuat Subfolder Workspace**
```bash
mkdir shared server client
```

* `shared/` — Skema state biner Colyseus dan interface TypeScript bersama.
* `server/` — Backend Colyseus WebSocket, Express REST API, dan integrasi database.
* `client/` — Frontend Vite, canvas game Phaser 3, dan antarmuka overlay DOM HTML/CSS.

## Setup Environment & Dependensi

**1. Konfigurasi Variabel Lingkungan (.env)**

File `server/.env`:
```bash title="server/.env"
PORT=2567
NODE_ENV=development
REDIS_URL=redis://127.0.0.1:6379
SUPABASE_URL=https://your-supabase-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-role-key
CLIENT_ORIGIN=http://localhost:5173
```

File `client/.env`:
```bash title="client/.env"
VITE_SERVER_URL=http://localhost:2567
VITE_SUPABASE_URL=https://your-supabase-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

**2. Konfigurasi package.json Setiap Workspace**

File `shared/package.json`:
```json title="shared/package.json"
{
  "name": "@zigma/shared",
  "version": "1.0.0",
  "main": "state.ts",
  "dependencies": {
    "@colyseus/schema": "^2.0.0"
  }
}
```

File `server/package.json`:
```json title="server/package.json"
{
  "name": "@zigma/server",
  "version": "1.0.0",
  "main": "src/server.ts",
  "scripts": {
    "dev": "ts-node-dev --respawn --transpile-only src/server.ts",
    "build": "tsc",
    "start": "node dist/server.js"
  },
  "dependencies": {
    "@colyseus/redis-driver": "^0.15.0",
    "@colyseus/redis-presence": "^0.15.0",

    "ioredis": "^5.11.1",
```

**3. Instalasi Seluruh Dependensi**

Jalankan perintah ini di root direktori project:
```bash
npm install
```

## Struktur Folder Project

Struktur dasar direktori workspace project Zigma yang terbentuk:

```text
MultiplayerGameQuiz/
├── package.json                         # Konfigurasi workspace root
├── shared/
│   ├── package.json                     # Dependensi modul shared
│   └── state.ts                         # Skema state biner Colyseus
├── server/
│   ├── .env                             # Konfigurasi lingkungan backend
│   ├── package.json                     # Dependensi backend
│   └── src/
│       ├── server.ts                    # Entrypoint server Express + Colyseus
│       ├── rooms/                       # Room logika dan event handler
│       └── utils/                       # Integrasi Supabase dan tilemap parser
└── client/
    ├── .env                             # Konfigurasi lingkungan frontend
    ├── package.json                     # Dependensi frontend
    ├── index.html                       # Entry container HTML
    └── src/
        ├── main.ts                      # Entrypoint aplikasi client
        ├── game.ts                      # Inisialisasi game instance Phaser 3
        ├── services/                    # Service koneksi WebSocket
        └── scenes/                      # Scene permainan (Lobby, Gameplay, Monitor)
```
