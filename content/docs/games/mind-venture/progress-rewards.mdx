# Scoring & Rewards

## Sistem Skor

Skor dihitung berdasarkan **ketepatan** dan **kecepatan** menjawab soal.

| Aksi | Poin |
| ---- | ---- |
| Jawaban benar | +100 |
| Time bonus | +timeLeft × 10 |
| Maksimal per soal | +250 (100 + 15×10) |
| Maksimal total (10 soal) | +2500 |

## Rumus Skor

```ts
// Per soal:
score = 100 + Math.floor(timeLeft * 10);

// Contoh:
// Waktu tersisa 15s → 100 + 150 = 250 poin
// Waktu tersisa 10s → 100 + 100 = 200 poin
// Waktu habis (0s) → 0 poin (salah)
```

## Leaderboard Room

Skor semua pemain di-ranking secara real-time:

```ts title="src/pages/LeaderboardPage.tsx"
const LeaderboardPage: React.FC = () => {
  const [players, setPlayers] = useState<Player[]>([]);

  useEffect(() => {
    // Subscribe ke leaderboard room
    const fetchData = async () => {
      const data = await getRoomLeaderboard(roomCode);
      setPlayers(data.sort((a, b) => b.score - a.score));
    };
    fetchData();
    const interval = setInterval(fetchData, 3000);
    return () => clearInterval(interval);
  }, [roomCode]);

  return (
    <div className="leaderboard">
      {players.map((player, index) => (
        <div key={player.id} className={index < 3 ? 'top-three' : ''}>
          <span>#{index + 1}</span>
          <span>{player.nickname}</span>
          <span>{player.score}</span>
        </div>
      ))}
    </div>
  );
};
```
