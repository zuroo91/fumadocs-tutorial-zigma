# Sistem Kategori

Pemain dapat memilih salah satu dari 6 kategori kuis sebelum memulai permainan.

## Daftar Kategori

| Kategori | Emoji | Deskripsi |
| -------- | ----- | --------- |
| Sains | 🔬 | Soal sains pengetahuan umum |
| Sejarah | 📜 | Soal sejarah Indonesia & dunia |
| Budaya | 🎭 | Soal budaya dan tradisi |
| Logika | 🧩 | Soal logika dan matematika |
| Olahraga | ⚽ | Soal olahraga |
| Teknologi | 💻 | Soal teknologi dan komputer |
