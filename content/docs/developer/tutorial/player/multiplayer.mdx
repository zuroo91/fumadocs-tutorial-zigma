# Membangun Service Multiplayer Klien (RoomService)

Pada modul ini, kamu akan membangun **`RoomService`** menggunakan `colyseus.js` untuk menghubungkan klien pemain ke game server melalui WebSocket persisten dan mendengarkan pembaruan state biner `@colyseus/schema`.

---

## Langkah 1: Membangun Singleton RoomService

Buat file `client/src/services/room/RoomService.ts`:

```typescript title="client/src/services/room/RoomService.ts"
import { Client, Room } from 'colyseus.js';
import type { GameState } from '@zigma/shared';

export class RoomService {
  private static instance: RoomService;
  private client: Client;
  private activeRoom: Room<GameState> | null = null;

  private constructor() {
    const serverUrl = import.meta.env.VITE_SERVER_URL || 'http://localhost:2567';
    this.client = new Client(serverUrl);
  }

  public static getInstance(): RoomService {
    if (!RoomService.instance) {
      RoomService.instance = new RoomService();
    }
    return RoomService.instance;
  }

  // Menghubungkan player ke room berdasarkan 6-digit PIN
  async joinRoomByPin(roomCode: string, options: { nickname: string; hairOption: string; isHost?: boolean }): Promise<Room<GameState>> {
    try {
      this.activeRoom = await this.client.joinOrCreate<GameState>("game_room", {
        roomCode,
        ...options
      });

      console.log(`Berhasil terhubung ke room: ${this.activeRoom.id} (PIN: ${roomCode})`);
      this.setupGlobalListeners();
      return this.activeRoom;
    } catch (error) {
      console.error("Gagal join ke room Colyseus:", error);
      throw error;
    }
  }

  private setupGlobalListeners() {
    if (!this.activeRoom) return;

    this.activeRoom.onLeave((code) => {
      console.warn(`Terputus dari room dengan kode: ${code}`);
      this.activeRoom = null;
    });

    this.activeRoom.onError((code, message) => {
      console.error(`Colyseus Error [${code}]: ${message}`);
    });
  }

  // Mengirim pembaruan koordinat pergerakan pemain ke server
  sendMovement(x: number, y: number) {
    if (this.activeRoom) {
      this.activeRoom.send("PLAYER_MOVE", { x, y });
    }
  }

  // Mengirim jawaban kuis ke server untuk divalidasi
  sendAnswer(questionId: string, selectedOption: string, timeRemainingRatio: number) {
    if (this.activeRoom) {
      this.activeRoom.send("SUBMIT_ANSWER", {
        questionId,
        selectedOption,
        timeRemainingRatio
      });
    }
  }

  getActiveRoom(): Room<GameState> | null {
    return this.activeRoom;
  }
}
```

* **File dibuat**: `client/src/services/room/RoomService.ts`
* **Fungsi**: Titik pusat komunikasi WebSocket antara game Phaser 3 di klien dan game server.
