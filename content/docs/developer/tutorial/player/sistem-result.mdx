# Membangun Kartu Hasil Personal (ResultManager)

Pada modul ini, kamu akan membangun **`ResultManager`** yang bertanggung jawab merender kartu evaluasi nilai personal pemain setelah sesi kuis berakhir, menampilkan total skor, akurasi pengerjaan, dan status peringkat.

![Kartu Hasil Personal Player Zigma](/images/result.png)

---

## Langkah 1: Mendefinisikan Struktur Data Hasil Player

Buat interface ringkasan performa di `client/src/types/result.ts`:

```typescript title="client/src/types/result.ts"
export interface PlayerResultSummary {
  nickname: string;
  hairOption: string;
  score: number;
  totalQuestions: number;
  correctAnswers: number;
  timeSpentSeconds: number;
  rank: number;
}
```

---

## Langkah 2: Membangun Komponen Kartu Hasil (ResultManager)

Buat file `client/src/scenes/player/ResultManager.ts`:

```typescript title="client/src/scenes/player/ResultManager.ts"
import type { PlayerResultSummary } from '../../types/result';

export class ResultManager {
  private container: HTMLDivElement;

  constructor(summary: PlayerResultSummary, onBackHome: () => void) {
    this.container = document.createElement('div');
    this.container.id = 'player-result-view';
    this.container.className = 'fixed inset-0 bg-gray-950 text-white flex items-center justify-center p-4 z-50 overflow-y-auto animate-fade-in';

    this.render(summary, onBackHome);
    document.body.appendChild(this.container);
  }

  private render(data: PlayerResultSummary, onBackHome: () => void) {
    const accuracy = Math.round((data.correctAnswers / Math.max(1, data.totalQuestions)) * 100);

    this.container.innerHTML = `
      <div class="bg-gray-900 border border-gray-800 rounded-3xl p-8 max-w-md w-full text-center shadow-2xl">
        <span class="text-xs uppercase tracking-widest text-teal-400 font-bold">HASIL PERTANDINGAN</span>
        <h2 class="text-3xl font-extrabold mt-1 mb-6 text-white">${data.nickname}</h2>

        <!-- Lingkaran Skor Besar -->
        <div class="relative w-36 h-36 mx-auto mb-6 flex flex-col items-center justify-center bg-gradient-to-tr from-purple-900/80 to-teal-900/80 rounded-full border-4 border-teal-400 shadow-xl">
          <span class="text-4xl font-black text-white font-mono">${data.score}</span>
          <span class="text-xs text-teal-200 font-semibold uppercase">Poin Total</span>
        </div>

        <!-- Statistik Performa -->
        <div class="grid grid-cols-2 gap-3 mb-8 text-left">
          <div class="bg-gray-800/80 p-3 rounded-xl border border-gray-700/50">
            <span class="text-xs text-gray-400">Peringkat</span>
            <p class="text-lg font-bold text-yellow-400 font-mono">#${data.rank}</p>
          </div>
          <div class="bg-gray-800/80 p-3 rounded-xl border border-gray-700/50">
            <span class="text-xs text-gray-400">Akurasi</span>
            <p class="text-lg font-bold text-teal-300 font-mono">${accuracy}%</p>
          </div>
          <div class="bg-gray-800/80 p-3 rounded-xl border border-gray-700/50">
            <span class="text-xs text-gray-400">Benar / Total</span>
            <p class="text-lg font-bold text-white font-mono">${data.correctAnswers} / ${data.totalQuestions}</p>
          </div>
          <div class="bg-gray-800/80 p-3 rounded-xl border border-gray-700/50">
            <span class="text-xs text-gray-400">Durasi</span>
            <p class="text-lg font-bold text-gray-300 font-mono">${data.timeSpentSeconds}s</p>
          </div>
        </div>

        <!-- Tombol Selesai -->
        <button id="btn-result-home" class="w-full py-3 bg-gradient-to-r from-purple-600 to-teal-500 hover:from-purple-500 hover:to-teal-400 rounded-xl font-bold transition shadow-lg">
          Kembali ke Beranda
        </button>
      </div>
    `;

    document.getElementById('btn-result-home')?.addEventListener('click', () => {
      this.destroy();
      onBackHome();
    });
  }

  public destroy() {
    this.container.remove();
  }
}
```

* **File dibuat**: `client/src/scenes/player/ResultManager.ts`
* **Fungsi**: Merender kartu ringkasan hasil personal kuis dan menghubungkan navigasi kembali ke beranda.
