# Membangun Sistem Aksi & Modal Kuis (QuizPopup)

Pada modul ini, kamu akan membangun logika deteksi tebasan pedang (*Attack Cone Hitbox*), transisi kamera sinematik zoom-in ke monster, serta komponen overlay DOM **`QuizPopup`** untuk menyajikan pertanyaan kuis secara interaktif.

## Langkah 1: Membangun Evaluasi Hitbox Serangan Pedang

Di dalam `client/src/scenes/player/GameScene.ts`, buat metode untuk mengevaluasi apakah tebasan pedang mengenai monster musuh di depannya:

```typescript title="client/src/scenes/player/GameScene.ts (Hitbox Serangan)"
performAttackHitbox(isFacingLeft: boolean) {
  const attackRange = 50; // Jangkauan tebasan dalam pixel
  const angleTolerance = Math.PI / 3; // Sudut kerucut serang 60 derajat

  this.enemiesGroup.getChildren().forEach((enemyObj: any) => {
    const enemy = enemyObj as Phaser.Physics.Arcade.Sprite;
    const dist = Phaser.Math.Distance.Between(
      this.playerSprite.x, this.playerSprite.y,
      enemy.x, enemy.y
    );

    if (dist <= attackRange) {
      const angleToEnemy = Phaser.Math.Angle.Between(
        this.playerSprite.x, this.playerSprite.y,
        enemy.x, enemy.y
      );
      const facingAngle = isFacingLeft ? Math.PI : 0;
      const angleDiff = Phaser.Math.Angle.Wrap(angleToEnemy - facingAngle);

      // Jika monster berada di dalam kerucut depan karakter
      if (Math.abs(angleDiff) <= angleTolerance) {
        this.triggerQuizInteraction(enemy);
      }
    }
  });
}
```

* **Fungsi**: Memeriksa koordinat jarak dan orientasi hadap pemain saat tombol serang ditekan.

## Langkah 2: Mengimplementasikan Transisi Kamera Sinematik

Saat tebasan terkonfirmasi mengenai monster, kunci pergerakan karakter dan jalankan animasi kamera:

```typescript title="client/src/scenes/player/GameScene.ts (Kamera Sinematik)"
triggerQuizInteraction(enemySprite: Phaser.Physics.Arcade.Sprite) {
  // Hentikan sementara kontrol karakter
  this.playerSprite.setVelocity(0, 0);
  this.isInteracting = true;

  // Animasi kamera fokus dan zoom ke monster
  this.cameras.main.stopFollow();
  this.cameras.main.pan(enemySprite.x, enemySprite.y, 800, 'Power2');
  this.cameras.main.zoomTo(3.5, 1000, 'Power2');

  // Tampilkan Modal Kuis setelah zoom selesai
  this.time.delayedCall(1000, () => {
    this.openQuizPopup(enemySprite);
  });
}
```

## Langkah 3: Membangun Komponen DOM Modal Kuis (QuizPopup)

Buat file `client/src/components/QuizPopup.ts`:

```typescript title="client/src/components/QuizPopup.ts"
export interface QuizQuestionData {
  id: string;
  questionText: string;
  imageUrl?: string;
  options: { key: string; text: string }[];
  durationSeconds: number;
}

export class QuizPopup {
  private container: HTMLDivElement;
  private timerInterval: any;
  private timeRemaining: number;
  private totalDuration: number;

  constructor(
    data: QuizQuestionData,
    onAnswer: (selectedOption: string, ratio: number) => void,
    onTimeout: () => void
  ) {
    this.totalDuration = data.durationSeconds || 20;
    this.timeRemaining = this.totalDuration;

    this.container = document.createElement('div');
    this.container.id = 'quiz-popup-overlay';
    this.container.className = 'fixed inset-0 bg-black/60 backdrop-blur-sm flex items-center justify-center p-4 z-40 animate-fade-in';

    this.render(data, onAnswer, onTimeout);
    document.body.appendChild(this.container);
    this.startTimer(onTimeout);
  }

  private render(data: QuizQuestionData, onAnswer: Function, onTimeout: Function) {
    this.container.innerHTML = `
      <div class="bg-gray-900 border-2 border-purple-500/50 rounded-3xl p-6 max-w-xl w-full text-white shadow-2xl">
        <!-- Bilah Timer Countdown -->
        <div class="w-full bg-gray-800 h-2 rounded-full overflow-hidden mb-6">
          <div id="quiz-timer-bar" class="bg-gradient-to-r from-teal-400 to-purple-500 h-full w-full transition-all duration-1000"></div>
        </div>

        <!-- Pertanyaan -->
        <h2 class="text-xl font-bold text-center mb-6 leading-relaxed">${data.questionText}</h2>

        <!-- Opsi Jawaban (Grid 2x2) -->
        <div class="grid grid-cols-1 sm:grid-cols-2 gap-3">
          ${data.options.map(opt => `
            <button class="btn-option p-4 bg-gray-800 hover:bg-purple-900/60 border border-gray-700 hover:border-purple-400 rounded-2xl font-semibold text-left transition transform active:scale-98 flex items-center gap-3" data-key="${opt.key}">
              <span class="w-8 h-8 bg-gray-700 rounded-lg flex items-center justify-center font-bold text-xs text-purple-300 uppercase">${opt.key}</span>
              <span class="text-sm">${opt.text}</span>
            </button>
          `).join('')}
        </div>
      </div>
    `;

    // Event listener tombol opsi
    this.container.querySelectorAll('.btn-option').forEach(btn => {
      btn.addEventListener('click', (e) => {
        clearInterval(this.timerInterval);
        const selectedKey = (e.currentTarget as HTMLElement).getAttribute('data-key') || '';
        const ratio = this.timeRemaining / this.totalDuration;
        this.destroy();
        onAnswer(selectedKey, ratio);
      });
    });
  }

  private startTimer(onTimeout: Function) {
    const bar = document.getElementById('quiz-timer-bar');
    this.timerInterval = setInterval(() => {
      this.timeRemaining--;
      if (bar) {
        bar.style.width = `${(this.timeRemaining / this.totalDuration) * 100}%`;
      }
      if (this.timeRemaining <= 0) {
        clearInterval(this.timerInterval);
        this.destroy();
        onTimeout();
      }
    }, 1000);
  }

  public destroy() {
    clearInterval(this.timerInterval);
    this.container.remove();
  }
}
```

* **File dibuat**: `client/src/components/QuizPopup.ts`
* **Fungsi**: Menyajikan pertanyaan kuis responsif dengan timer countdown visual dan pengiriman rasio waktu.
