# Membangun Modul Setup & Autentikasi

Pada modul ini, kamu akan membangun sistem autentikasi klien menggunakan **Supabase SSO** (`@supabase/supabase-js` dan `@supabase/ssr`). Sistem ini bertindak sebagai penjaga akses untuk memverifikasi akun Host sebelum mereka dapat membuat dan mengelola kuis.

## Langkah 1: Menyiapkan File Klien Supabase Frontend

Buat file baru di `client/src/services/auth/supabaseClient.ts` untuk menginisialisasi instance Supabase menggunakan kredensial dari variabel lingkungan:

```typescript title="client/src/services/auth/supabaseClient.ts"
import { createClient } from '@supabase/supabase-js';

const supabaseUrl = import.meta.env.VITE_SUPABASE_URL;
const supabaseAnonKey = import.meta.env.VITE_SUPABASE_ANON_KEY;

if (!supabaseUrl || !supabaseAnonKey) {
  throw new Error('Supabase URL atau Anon Key belum dikonfigurasi pada file .env');
}

export const supabase = createClient(supabaseUrl, supabaseAnonKey);
```

* **File dibuat**: `client/src/services/auth/supabaseClient.ts`
* **Fungsi**: Menyediakan instance Supabase yang dapat digunakan kembali di seluruh komponen client.

## Langkah 2: Membangun Service Autentikasi (AuthService)

Buat file `client/src/services/auth/AuthService.ts` untuk mengelola login, logout, OAuth Google, dan pemeriksaan sesi aktif:

```typescript title="client/src/services/auth/AuthService.ts"
import { supabase } from './supabaseClient';
import type { User, Session } from '@supabase/supabase-js';

export class AuthService {
  private static instance: AuthService;
  private currentUser: User | null = null;
  private currentSession: Session | null = null;

  private constructor() {}

  public static getInstance(): AuthService {
    if (!AuthService.instance) {
      AuthService.instance = new AuthService();
    }
    return AuthService.instance;
  }

  // Memeriksa sesi login saat aplikasi pertama kali dimuat
  async checkSession(): Promise<User | null> {
    const { data: { session }, error } = await supabase.auth.getSession();
    if (error || !session) {
      this.currentUser = null;
      this.currentSession = null;
      return null;
    }
    this.currentUser = session.user;
    this.currentSession = session;
    return this.currentUser;
  }

  // Login menggunakan Email dan Password
  async signInWithEmail(email: string, password: string) {
    const { data, error } = await supabase.auth.signInWithPassword({
      email,
      password,
    });
    if (error) throw error;
    this.currentUser = data.user;
    this.currentSession = data.session;
    return data;
  }

  // Login menggunakan OAuth Google
  async signInWithGoogle() {
    const { data, error } = await supabase.auth.signInWithOAuth({
      provider: 'google',
      options: {
        redirectTo: window.location.origin,
      },
    });
    if (error) throw error;
    return data;
  }

  // Logout dan membersihkan sesi lokal
  async signOut(): Promise<void> {
    await supabase.auth.signOut();
    this.currentUser = null;
    this.currentSession = null;
  }

  getUser(): User | null {
    return this.currentUser;
  }

  isAuthenticated(): boolean {
    return this.currentUser !== null;
  }
}
```

* **File dibuat**: `client/src/services/auth/AuthService.ts`
* **Fungsi**: Mengelola status autentikasi Host secara terpusat (*Singleton Pattern*).

## Langkah 3: Menyiapkan Integrasi Supabase di Sisi Server

Di sisi backend, buat file `server/src/utils/supabase.ts` menggunakan **Service Role Key** agar server memiliki hak akses untuk memvalidasi token dan menyimpan data sesi permainan tanpa terhalang RLS (Row Level Security):

```typescript title="server/src/utils/supabase.ts"
import { createClient } from '@supabase/supabase-js';
import dotenv from 'dotenv';

dotenv.config();

const supabaseUrl = process.env.SUPABASE_URL || '';
const supabaseServiceKey = process.env.SUPABASE_SERVICE_ROLE_KEY || '';

export const supabaseServer = createClient(supabaseUrl, supabaseServiceKey, {
  auth: {
    persistSession: false,
    autoRefreshToken: false,
  },
});
```

* **File dibuat**: `server/src/utils/supabase.ts`
* **Fungsi**: Mengizinkan server Node.js membaca bank soal kuis dan menyimpan hasil akhir ke database PostgreSQL.

## Langkah 4: Memasang Listener Perubahan Sesi di Entrypoint

Di file `client/src/main.ts`, inisialisasi pengecekan sesi autentikasi saat aplikasi pertama kali dijalankan:

```typescript title="client/src/main.ts"
import { AuthService } from './services/auth/AuthService';

async function bootstrapApp() {
  const auth = AuthService.getInstance();
  const user = await auth.checkSession();
  
  console.log(user ? `Host terautentikasi: ${user.email}` : 'Masuk sebagai Player publik');
}

bootstrapApp();
```

Dengan langkah ini, fondasi autentikasi telah selesai dan siap digunakan pada alur pembuatan room kuis.
