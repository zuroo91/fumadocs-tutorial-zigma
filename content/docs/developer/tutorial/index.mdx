# Tutorial Membangun Game Zigma dari Nol

Panduan ini disusun secara bertahap untuk memandu kamu membangun game **Zigma** (*Educational 2D Top-Down Multiplayer Quiz Arcade*) dari awal (*from scratch*) berdasarkan arsitektur dan source code yang sebenarnya.

Setiap modul tutorial menjelaskan **file yang dibuat/diubah**, **fungsi kode**, **alur logika antar-sistem**, dan **kode program yang dapat langsung diimplementasikan**.

---

## Urutan Pembangunan Fitur (Roadmap)

Pembangunan Zigma dibagi menjadi beberapa tahapan modul yang terstruktur:

```
[ Setup & Autentikasi ]
         │
         ▼
[ Homepage & Kustomisasi Avatar ]
         │
         ├───► [ Alur Player: Join Room ──► Gameplay 2D ──► QuizPopup ──► Player Result ]
         │
         └───► [ Alur Host: Create Room ──► Host Lobby (QR) ──► Live Spectator ──► Leaderboard ]
         │
         ▼
[ Scoring & Bot Simulator Testing ]
```

---

## Daftar Modul Tutorial

### 1. Fondasi & Autentikasi
* **[Setup & Autentikasi](/docs/tutorial/setup-autentikasi)** — Inisialisasi struktur workspace, konfigurasi environment, dan integrasi autentikasi SSO Supabase (`AuthService`).
* **[Homepage & Dashboard](/docs/tutorial/homepage-dashboard)** — Membangun antarmuka beranda, bootstrap DOM di atas Phaser 3, sistem multi-bahasa, dan pemilih avatar rambut karakter.

### 2. Sisi Player (Klien Peserta)
* **[Join Session](/docs/tutorial/join/join-session)** — Mengimplementasikan form input PIN 6-digit, validasi nickname, dan scanner QR Code (`html5-qrcode`).
* **[Mode Multipemain](/docs/tutorial/player/multiplayer)** — Membangun `RoomService` menggunakan `colyseus.js` untuk sinkronisasi state biner WebSocket secara real-time.
* **[Sistem Gameplay](/docs/tutorial/player/sistem-gameplay)** — Membangun scene 2D Phaser 3, parsing tilemap Tiled, kontrol pergerakan (WASD & Virtual Joystick), dan interaksi peti harta karun.
* **[Sistem Quiz](/docs/tutorial/player/sistem-kuis)** — Membangun hitbox tebasan pedang, efek kamera sinematik zoom-in, dan modal interaktif `QuizPopup`.
* **[Sistem Result](/docs/tutorial/player/sistem-result)** — Membangun antarmuka `ResultManager` untuk kartu evaluasi nilai dan statistik personal siswa.

### 3. Sisi Host (Klien Penyelenggara & Server)
* **[Host: Create Room](/docs/tutorial/host/create-room)** — Membangun logika pembuatan room di server Colyseus (`GameRoom.ts`), query bank soal Supabase, dan pembagian PIN 6-digit.
* **[Host: Host Lobby](/docs/tutorial/host/host-lobby)** — Membangun scene ruang tunggu `HostWaitingRoomScene`, generator QR Code join, pemantauan daftar peserta, dan broadcast mulai game.
* **[Host: Host Monitor](/docs/tutorial/host/host-monitor)** — Membangun scene live spectator `HostProgressScene` untuk memantau pergerakan karakter dan bilah progres kuis seluruh peserta.
* **[Scoring & Rewards](/docs/tutorial/host/progress-rewards)** — Mengimplementasikan formula kalkulasi skor authoritative server, bonus kecepatan, dan buff peti arena.
* **[Leaderboard & Ranking](/docs/tutorial/host/leaderboard-ranking)** — Membangun tampilan podium 3 besar, tabel klasemen akhir, dan sinkronisasi hasil kuis ke PostgreSQL.

### 4. Pengujian & Deployment
* **[Deploy & Testing](/docs/tutorial/deploy-testing)** — Membangun `BotSimulatorManager` untuk simulasi beban multi-klien dan persiapan deployment server produksi.
