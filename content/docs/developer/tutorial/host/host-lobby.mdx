# Membangun Host Lobby & QR Code Generator

Pada modul ini, kamu akan membangun tampilan ruang tunggu Host (`HostWaitingRoomScene`) yang bertugas menampilkan PIN 6-digit, me-render QR Code join menggunakan library `qrcode`, serta memantau daftar peserta yang masuk secara real-time.

![Host Lobby Zigma](/images/host-lobby.png)

---

## Langkah 1: Membangun Generator QR Code Interaktif

Buat file utilitas `client/src/utils/qrGenerator.ts` menggunakan library `qrcode` untuk menghasilkan gambar data URL QR Code dari link room:

```typescript title="client/src/utils/qrGenerator.ts"
import QRCode from 'qrcode';

export async function generateRoomQRCode(roomCode: string): Promise<string> {
  const joinUrl = `${window.location.origin}/#/join?pin=${roomCode}`;
  try {
    return await QRCode.toDataURL(joinUrl, {
      width: 256,
      margin: 2,
      color: {
        dark: '#2D3436',
        light: '#FFFFFF'
      }
    });
  } catch (err) {
    console.error('Gagal membuat QR Code:', err);
    return '';
  }
}
```

* **File dibuat**: `client/src/utils/qrGenerator.ts`
* **Fungsi**: Mengonversi URL room Zigma menjadi gambar base64 QR Code siap render.

## Langkah 2: Membangun Komponen Antarmuka Host Lobby

Buat file `client/src/scenes/host/HostWaitingRoomScene.ts` untuk mengelola UI ruang tunggu Host:

```typescript title="client/src/scenes/host/HostWaitingRoomScene.ts"
import { RoomService } from '../../services/room/RoomService';
import { generateRoomQRCode } from '../../utils/qrGenerator';

export class HostWaitingRoomScene {
  private container: HTMLDivElement;
  private roomService = RoomService.getInstance();
  private roomCode: string;

  constructor(roomCode: string) {
    this.roomCode = roomCode;
    this.container = document.createElement('div');
    this.container.id = 'host-lobby-view';
    this.container.className = 'fixed inset-0 bg-gray-950 text-white flex flex-col p-8 z-20';

    this.init();
  }

  private async init() {
    const qrDataUrl = await generateRoomQRCode(this.roomCode);

    this.container.innerHTML = `
      <!-- Header PIN & QR -->
      <div class="flex justify-between items-center bg-gray-900/80 p-6 rounded-2xl border border-gray-800 mb-8">
        <div>
          <span class="text-sm text-gray-400 uppercase tracking-wider">PIN GAME</span>
          <h1 class="text-6xl font-black text-transparent bg-clip-text bg-gradient-to-r from-purple-400 to-teal-300 font-mono tracking-widest">${this.roomCode}</h1>
        </div>
        <div class="flex items-center gap-4">
          <img src="${qrDataUrl}" alt="QR Code" class="w-24 h-24 rounded-xl border-2 border-purple-500 shadow-md" />
          <div class="text-right">
            <span id="player-count" class="text-2xl font-bold text-teal-400">0</span>
            <p class="text-xs text-gray-400">Pemain Bergabung</p>
          </div>
        </div>
      </div>

      <!-- Daftar Kartu Pemain -->
      <div class="flex-1 overflow-y-auto">
        <h3 class="text-lg font-bold text-gray-300 mb-4">Daftar Pemain:</h3>
        <div id="player-grid" class="grid grid-cols-2 sm:grid-cols-4 md:grid-cols-6 gap-4"></div>
      </div>

      <!-- Tombol Start Game -->
      <div class="flex justify-end pt-4 border-t border-gray-800">
        <button id="btn-start-game" class="px-8 py-4 bg-gradient-to-r from-purple-600 to-teal-500 hover:from-purple-500 hover:to-teal-400 font-extrabold text-lg rounded-2xl shadow-xl transition transform active:scale-95">
          Mulai Permainan 🚀
        </button>
      </div>
    `;

    document.body.appendChild(this.container);
    this.setupListeners();
  }

  private setupListeners() {
    const room = this.roomService.getActiveRoom();
    if (!room) return;

    // Sinkronisasi penambahan pemain baru
    room.state.players.onAdd((player, sessionId) => {
      this.updatePlayerGrid();
    });

    // Sinkronisasi pengurangan pemain saat keluar
    room.state.players.onRemove((player, sessionId) => {
      this.updatePlayerGrid();
    });

    // Tombol Mulai Game
    document.getElementById('btn-start-game')?.addEventListener('click', () => {
      room.send("START_GAME");
      window.location.hash = `#/host/${this.roomCode}/progress`;
    });
  }

  private updatePlayerGrid() {
    const room = this.roomService.getActiveRoom();
    const grid = document.getElementById('player-grid');
    const countEl = document.getElementById('player-count');
    if (!room || !grid || !countEl) return;

    grid.innerHTML = '';
    let count = 0;

    room.state.players.forEach((player) => {
      if (!player.isHost) {
        count++;
        const card = document.createElement('div');
        card.className = 'bg-gray-900 border border-gray-800 p-3 rounded-xl flex items-center gap-3 animate-fade-in';
        card.innerHTML = `
          <div class="w-10 h-10 bg-purple-900/50 rounded-lg flex items-center justify-center font-bold text-purple-300">
            ${player.nickname.charAt(0).toUpperCase()}
          </div>
          <span class="font-semibold text-sm truncate">${player.nickname}</span>
        `;
        grid.appendChild(card);
      }
    });

    countEl.textContent = count.toString();
  }

  public destroy() {
    this.container.remove();
  }
}
```

* **File dibuat**: `client/src/scenes/host/HostWaitingRoomScene.ts`
* **Fungsi**: Menangani visualisasi ruang tunggu dan memicu event `START_GAME` ke server.
