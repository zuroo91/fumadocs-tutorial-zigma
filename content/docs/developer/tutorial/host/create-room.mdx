# Membangun Fitur Create Room (Host)

Pada modul ini, kamu akan membangun logika pembuatan room kuis di sisi server Colyseus (`GameRoom.ts`), pembuatan PIN unik 6-digit, serta query bank soal kuis dari database Supabase.

---

## Langkah 1: Mendefinisikan Skema State Room Bersama (shared/state.ts)

Buat file `shared/state.ts` menggunakan `@colyseus/schema` untuk mendefinisikan state sinkronisasi room:

```typescript title="shared/state.ts"
import { Schema, MapSchema, type } from '@colyseus/schema';

export class Player extends Schema {
  @type("string") id: string = "";
  @type("string") nickname: string = "";
  @type("string") hairOption: string = "SHORT";
  @type("number") x: number = 200;
  @type("number") y: number = 200;
  @type("number") score: number = 0;
  @type("number") answeredCount: number = 0;
  @type("boolean") isHost: boolean = false;
  @type("boolean") isReady: boolean = false;
}

export class Question extends Schema {
  @type("string") id: string = "";
  @type("string") questionText: string = "";
  @type("string") optionA: string = "";
  @type("string") optionB: string = "";
  @type("string") optionC: string = "";
  @type("string") optionD: string = "";
  @type("string") correctAnswer: string = ""; // Disembunyikan dari payload klien publik
}

export class GameState extends Schema {
  @type("string") roomCode: string = "";
  @type("string") status: string = "LOBBY"; // LOBBY, PLAYING, FINISHED
  @type("number") timeRemaining: number = 600; // 10 Menit default
  @type({ map: Player }) players = new MapSchema<Player>();
}
```

* **File dibuat**: `shared/state.ts`
* **Fungsi**: Skema biner yang diserialisasi otomatis antara server dan klien.

## Langkah 2: Membangun Logika Room Server (server/src/rooms/GameRoom.ts)

Buat file `server/src/rooms/GameRoom.ts` yang menangani siklus hidup (*lifecycle*) room:

```typescript title="server/src/rooms/GameRoom.ts"
import { Room, Client } from 'colyseus';
import { GameState, Player } from '@zigma/shared';
import { supabaseServer } from '../utils/supabase';

export class GameRoom extends Room<GameState> {
  maxClients = 50;
  private quizQuestions: any[] = [];

  onCreate(options: any) {
    this.setState(new GameState());
    
    // Buat PIN 6-digit unik
    this.state.roomCode = options.roomCode || Math.floor(100000 + Math.random() * 900000).toString();
    this.setPrivate(); // Room diakses langsung via PIN

    // Mengambil soal kuis dari database Supabase
    if (options.quizId) {
      this.loadQuizData(options.quizId);
    }

    // Handler pesan kontrol dari Host
    this.onMessage("START_GAME", (client) => {
      const player = this.state.players.get(client.sessionId);
      if (player && player.isHost && this.state.status === "LOBBY") {
        this.state.status = "PLAYING";
        this.broadcast("GAME_STARTED", { startTime: Date.now() });
      }
    });

    this.onMessage("PLAYER_MOVE", (client, data: { x: number; y: number }) => {
      const player = this.state.players.get(client.sessionId);
      if (player) {
        player.x = data.x;
        player.y = data.y;
      }
    });
  }

  async loadQuizData(quizId: string) {
    const { data, error } = await supabaseServer
      .from('quizzes')
      .select('*, questions(*)')
      .eq('id', quizId)
      .single();

    if (!error && data) {
      this.quizQuestions = data.questions || [];
    }
  }

  onJoin(client: Client, options: any) {
    const player = new Player();
    player.id = client.sessionId;
    player.nickname = options.nickname || `Player_${client.sessionId.substring(0, 4)}`;
    player.hairOption = options.hairOption || "SHORT";
    player.isHost = !!options.isHost;

    this.state.players.set(client.sessionId, player);
    console.log(`Player ${player.nickname} (${client.sessionId}) bergabung ke room ${this.state.roomCode}`);
  }

  onLeave(client: Client) {
    this.state.players.delete(client.sessionId);
  }
}
```

* **File dibuat**: `server/src/rooms/GameRoom.ts`
* **Fungsi**: Authoritative server yang mengelola state kuis, koneksi peserta, dan pesan jaringan.

## Langkah 3: Mendaftarkan Room di Server Entrypoint

Di `server/src/server.ts`, daftarkan `GameRoom` ke server Colyseus:

```typescript title="server/src/server.ts"
import { Server } from 'colyseus';
import { createServer } from 'http';
import express from 'express';
import { GameRoom } from './rooms/GameRoom';

const app = express();
const port = Number(process.env.PORT) || 2567;
const httpServer = createServer(app);

const gameServer = new Server({
  server: httpServer,
});

// Daftarkan room dengan identifier "game_room"
gameServer.define("game_room", GameRoom);

httpServer.listen(port, () => {
  console.log(`Server Colyseus Zigma aktif di port ${port}`);
});
```

Dengan langkah ini, server siap menerima permintaan pembuatan room baru dari Host dan mengelola sinkronisasi multi-klien secara real-time.
