# Membangun Fitur Join Session & QR Scanner

Pada modul ini, kamu akan membangun logika klien untuk memvalidasi PIN 6-digit, membaca QR Code menggunakan kamera browser (`html5-qrcode`), dan menghubungkan player ke server Colyseus.

---

## Langkah 1: Membangun Komponen QR Code Scanner

Buat file `client/src/components/QRScannerModal.ts` menggunakan library `html5-qrcode` untuk membaca QR Code dari kamera smartphone:

```typescript title="client/src/components/QRScannerModal.ts"
import { Html5QrcodeScanner } from 'html5-qrcode';

export class QRScannerModal {
  private scanner: Html5QrcodeScanner | null = null;
  private modalContainer: HTMLDivElement;

  constructor(onSuccess: (decodedPin: string) => void, onClose: () => void) {
    this.modalContainer = document.createElement('div');
    this.modalContainer.className = 'fixed inset-0 bg-black/80 flex items-center justify-center z-50 p-4';
    
    this.modalContainer.innerHTML = `
      <div class="bg-gray-900 border border-gray-700 rounded-2xl p-6 max-w-sm w-full text-center text-white">
        <h3 class="text-xl font-bold mb-4">Pindai QR Code Room</h3>
        <div id="qr-reader" class="w-full rounded-xl overflow-hidden mb-4"></div>
        <button id="btn-close-qr" class="w-full py-2 bg-gray-800 hover:bg-gray-700 rounded-xl text-sm font-semibold transition">
          Tutup Kamera
        </button>
      </div>
    `;

    document.body.appendChild(this.modalContainer);
    this.startScanner(onSuccess);

    document.getElementById('btn-close-qr')?.addEventListener('click', () => {
      this.close();
      onClose();
    });
  }

  private startScanner(onSuccess: (pin: string) => void) {
    this.scanner = new Html5QrcodeScanner(
      "qr-reader",
      { fps: 10, qrbox: { width: 250, height: 250 } },
      false
    );

    this.scanner.render(
      (decodedText) => {
        // Ekstrak 6-digit PIN dari URL atau teks QR
        const pinMatch = decodedText.match(/\b\d{6}\b/);
        if (pinMatch) {
          const pin = pinMatch[0];
          this.close();
          onSuccess(pin);
        }
      },
      (error) => {
        // Mengabaikan frame scan yang belum mendeteksi QR
      }
    );
  }

  public close() {
    if (this.scanner) {
      this.scanner.clear().catch(console.error);
    }
    this.modalContainer.remove();
  }
}
```

* **File dibuat**: `client/src/components/QRScannerModal.ts`
* **Fungsi**: Membuka kamera browser secara otomatis dan mengekstrak PIN 6-digit saat barcode terdeteksi.

## Langkah 2: Memvalidasi Input PIN & Nickname

Buat file validator `client/src/utils/validation.ts`:

```typescript title="client/src/utils/validation.ts"
export interface JoinPayload {
  nickname: string;
  roomCode: string;
  hairOption: string;
}

export function validateJoinInput(nickname: string, pin: string, hair: string): { isValid: boolean; error?: string } {
  if (!nickname || nickname.trim().length === 0) {
    return { isValid: false, error: 'Nickname tidak boleh kosong.' };
  }
  if (nickname.trim().length > 15) {
    return { isValid: false, error: 'Nickname maksimal 15 karakter.' };
  }
  if (!/^\d{6}$/.test(pin.trim())) {
    return { isValid: false, error: 'PIN Room harus terdiri dari tepat 6 digit angka.' };
  }
  return { isValid: true };
}
```

## Langkah 3: Menghubungkan Player ke Room Colyseus

Pada handler aksi join di `client/src/main.ts`, hubungkan validasi input ke pemanggilan service room:

```typescript title="client/src/main.ts (Potongan Logika Join)"
import { validateJoinInput } from './utils/validation';
import { RoomService } from './services/room/RoomService';

async function handlePlayerJoin(nickname: string, pin: string, hair: string) {
  const check = validateJoinInput(nickname, pin, hair);
  if (!check.isValid) {
    alert(check.error);
    return;
  }

  try {
    const roomService = RoomService.getInstance();
    // Bergabung ke room Colyseus dengan mengirim payload identitas player
    await roomService.joinRoomByPin(pin, {
      nickname: nickname.trim(),
      hairOption: hair,
      isHost: false
    });

    // Simpan identitas ke sessionStorage untuk pemulihan state saat refresh
    sessionStorage.setItem('zigma_player_name', nickname.trim());
    sessionStorage.setItem('zigma_room_code', pin.trim());

    // Alihkan ke Scene Waiting Room / Game Player
    window.location.hash = `#/player/${pin}/game`;
  } catch (err: any) {
    alert(`Gagal masuk ke room: ${err.message || 'Room tidak ditemukan atau sudah penuh.'}`);
  }
}
```

Dengan langkah ini, alur bergabung bagi player telah lengkap mulai dari pemindaian kamera, validasi lokal, hingga inisialisasi sesi WebSocket.
