# Membangun Bot Simulator & Testing

Pada modul ini, kamu akan membangun **`BotSimulatorManager`** untuk melakukan load testing room Colyseus dengan mensimulasikan banyak klien bot otomatis yang bergabung, bergerak, dan menjawab soal kuis secara acak.

---

## Langkah 1: Membangun Kelas Bot Simulator

Buat file `client/src/test/BotSimulatorManager.ts`:

```typescript title="client/src/test/BotSimulatorManager.ts"
import { Client } from 'colyseus.js';

export interface BotConfig {
  count: number;
  roomCode: string;
  moveIntervalMs: number;
  answerDelayMs: number;
}

export class BotSimulatorManager {
  private bots: any[] = [];
  private serverUrl: string;

  constructor(serverUrl: string) {
    this.serverUrl = serverUrl;
  }

  async spawnBots(config: BotConfig) {
    console.log(`Menjalankan ${config.count} bot ke room ${config.roomCode}...`);

    for (let i = 0; i < config.count; i++) {
      await this.spawnSingleBot(config, i + 1);
      // Jeda 200ms antar spawn agar server tidak overload
      await new Promise(res => setTimeout(res, 200));
    }

    console.log(`${config.count} bot berhasil terhubung.`);
  }

  private async spawnSingleBot(config: BotConfig, botIndex: number) {
    try {
      const client = new Client(this.serverUrl);
      const room = await client.joinOrCreate("game_room", {
        roomCode: config.roomCode,
        nickname: `Bot_${botIndex}`,
        hairOption: 'SHORT',
        isHost: false
      });

      this.bots.push(room);

      // Pergerakan acak berulang
      const moveInterval = setInterval(() => {
        const x = 100 + Math.random() * 800;
        const y = 100 + Math.random() * 600;
        room.send("PLAYER_MOVE", { x: Math.round(x), y: Math.round(y) });
      }, config.moveIntervalMs || 1000);

      // Simulasi menjawab soal acak
      room.onMessage("QUIZ_QUESTION", (data: any) => {
        setTimeout(() => {
          const options = ['A', 'B', 'C', 'D'];
          const randomAnswer = options[Math.floor(Math.random() * 4)];
          room.send("SUBMIT_ANSWER", {
            questionId: data.id,
            selectedOption: randomAnswer,
            timeRemainingRatio: Math.random()
          });
        }, config.answerDelayMs || 2000);
      });

      room.onLeave(() => clearInterval(moveInterval));
    } catch (err) {
      console.error(`Gagal menjalankan bot #${botIndex}:`, err);
    }
  }

  disconnectAll() {
    this.bots.forEach(room => room.leave());
    this.bots = [];
    console.log('Semua bot telah diputus koneksinya.');
  }
}
```

* **File dibuat**: `client/src/test/BotSimulatorManager.ts`
* **Fungsi**: Mensimulasikan puluhan klien pemain virtual secara bersamaan untuk menguji stabilitas server.

## Langkah 2: Menjalankan Simulasi dari Skrip CLI

Buat skrip pengujian `test/run-bots.ts` di sisi server atau di direktori root project:

```typescript title="test/run-bots.ts"
import { BotSimulatorManager } from '../client/src/test/BotSimulatorManager';

const simulator = new BotSimulatorManager('http://localhost:2567');

simulator.spawnBots({
  count: 20,
  roomCode: '849201', // Ganti dengan PIN room aktif
  moveIntervalMs: 800,
  answerDelayMs: 3000
});

// Hentikan simulasi setelah 2 menit
setTimeout(() => {
  simulator.disconnectAll();
  process.exit(0);
}, 2 * 60 * 1000);
```

Jalankan dengan `ts-node test/run-bots.ts` untuk memulai simulasi beban.

## Langkah 3: Memantau Performa Room Colyseus

Colyseus menyediakan built-in monitor dashboard di endpoint `/colyseus` jika diaktifkan di server:

```typescript title="server/src/server.ts (Monitor Dashboard)"
import { monitor } from '@colyseus/monitor';

// Tambahkan setelah deklarasi app Express
app.use('/colyseus', monitor());
```

Buka `http://localhost:2567/colyseus` di browser untuk melihat:
* Jumlah room aktif dan klien yang terhubung
* Ukuran state room dan frekuensi update
* Latency rata-rata WebSocket setiap koneksi
