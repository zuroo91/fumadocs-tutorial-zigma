# Deploy & Monitoring

- **Frontend** → Vercel (auto-deploy dari GitHub)
- **Socket server** → Railway atau Fly.io
- **Firebase** → sudah di-host oleh Google
- **Monitoring** → Sentry untuk error tracking, PostHog untuk analytics

Lihat panduan lengkap di [**Tutorial: Deploy & Testing**](/docs/tutorial/deploy-testing).
